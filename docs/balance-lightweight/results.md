高现金建房路径也曾降至30现金，说明机器人后续投入和路径风险需核对。不能从这个局面断言地产弱，或从股票有利路径断言投资强。12组中10组末随机调用计数不同，连同不同资产和选择会使后续轨迹分歧；这些末值不是全局因果或胜率估计。

本次短分支仅采用两人人工局面和一个统一后续策略；没有覆盖全部人数、玩法路线、地图/资讯序列或真人决策。没有将期末资产或现金领先计成胜场。

## 4. 长局与机遇组合

已核对的H5＋H10组合，在持有三座有效城市股票、自己城市不超过两座时，起点经营奖励额外4,000；资格失效后奖励相应减少。基础起点奖励10,000另计。两者是**合法的持续现金来源**，不是无成本套利证明：持仓和资产条件需要成本，绕圈和生存也需要时间。

H6＋H11在标准租金6,000的案例中，实付4,320，银行补足1,680，城主现金4,800、基金暂存1,200。付款减免与银行补足分别记录；这是既定规则，有可能影响现金恢复节奏，不能凭一例确认长局因果。

短窗口还存在大量建设、购买、罚金等现金回收，无法仅凭上述奖励推出“现金总是上涨”。部分资金变化记为未分类净额，未假装已完整拆解中后期。前轮35/120局到500轮的长局现象仍是优先调查依据；本轮未跑终局，不独立证明局长改善或原因。

## 5. 四类结论与后续排序

| 类别 | 本轮结论 |
|---|---|
| 已确认具体游戏问题 | 所检范围没有发现；两次工具问题已限定修复，见下文 |
| 值得复核的风险 | 即时投入压缩流动性、后续机器人投入；持续起点奖励与防御银行补足可能影响长局 |
| 所检范围未发现明显风险 | 已检账务/额度/组合与局部身份顺序符合预期 |
| 未验证/证据不足 | 总体座位/路线胜率、所有组合/路径、正常开局可达性、真人理解和游戏时长 |

下一轮建议优先三项：

1. **经营风险提示**：在现有建房、股票和机票预览中清楚显示实付后余额和已有可见租金压力，保持按钮含义。成功依据是玩家能理解费用与风险，不是给玩家保证收益；提示失准则回退。
2. **长局单项候选**：先核对现金来源，再只选择起点阶段奖励或一项组合条件做明确对照。当前没有依据同时削减全部机遇；若只缩短对局却明显扩大路线压力，候选不放行。
3. **机器人策略复核**：核对现金储备、主动投入、窗口记忆和股票/航线估值，区分策略问题与规则问题。新策略独立版本登记，不能覆盖旧策略/旧证据或直接用它宣布公平。

具体产品/规则改动另立ic-spec规格；本轮不自动实施。原51项胜率比较“证据不足”的结论保持，真人局面体验未执行。
