# 半小时快速模式 Spec

版本：v1.0。日期：2026-10-09。状态：规格与技术设计已批准，任务拆解与验收清单已批准；进入开发。

## 背景与目标

当前普通模式以最后存活者获胜，局长难以提前安排。用户已确认加入普通和快速两种模式，并选择从正式开局计时30分钟，到时封盘结算，不等完整轮次，掉线不延长总时限。

本轮交付快速模式的完整入口、总计时、决定时限、终局处理、排名和解释，并接入已批准的快速机遇成长与后续换路线时点。普通模式保持原节奏与获胜条件。

本规格沿用此前已确认的目标与快速提案，补齐末端处理。2026-10-09用户在明确的spec审批请求后回复“继续”，批准本规格进入技术设计；批准不代表实现或上线。

## 时间与结算术语

- **正式开局**：服务端确认房主合法开始并建立本局状态的时刻；包含第一阶段机遇选择。大厅等人不计入。
- **总截止**：正式开局后30分钟；个人等待、动画、离线暂停均不延后。
- **已成立操作**：服务端在总截止前完成资格检查并提交结果；手机点击、仅发送请求、本地草稿和未完成拍卖报价都不代表成交。
- **封盘**：停止新动作及新决定，收尾已成立事实，结清收益，形成唯一结束状态。不是再自动执行完当前回合。
- **净资产**：用于快速排名的资产减负债；与当前没有扣负债的资产总览区分。
- **安全交接**：既有购买、落点、自救、股票、拍卖或转让已完成，允许进入新初始机遇阶段的回合交接位置。

## 功能需求

### F1 房间选择与规则固定

房主开局前选择普通或快速，默认普通；房间所有成员看见本局模式和快速30分钟说明。开局后不能更改模式或总时长，非房主不能改设置。两种模式均支持2–4人。

模式及新规则在正式开局前一致确认。旧页面不能误开它无法正确操作的新模式，应给出刷新提示；已经开始的旧对局不迁移。非法模式拒绝，不静默当作普通模式。

### F2 服务端总时钟与提示

服务端从正式开局起统一计算总时长，显示整局倒计时，并与当前个人决定倒计时清楚区分。剩5分钟及2分钟时分别提示即将按净资产排名，同一预告不因刷新或重连重复生成事件。

正常服务运行期间，到时封盘不等完整轮次；全员离线也不停止总时钟。客户端收到终局消息可以有网络延迟，不承诺每台手机在同一秒显示结果。无服务重启存档能力时，不宣称能够跨重启恢复剩余时间。

### F3 快速决定时限

快速模式单人一般决定最多20秒，包括掷骰、极地、监狱、城市或机场购买、建设、筹资购置、飞行、股票、拍卖应答、直接出售应答与转让确认。自救最多45秒；初始公共机遇选择最多30秒；后续个人路线选择最多20秒。

新决定按其类型开始计时；同一决定的查看、返回、无效输入、报价更新、重试、股票子面板不能重新计时。全部决定同时受总截止约束。早于总截止的超时沿用当前正式默认动作；封盘时不再调用默认动作来补回合。

本项目接入正式采用的离线策略。离线推进另行设计；在该项未交付前，原决定暂停仍可存在，但不能暂停快速总时钟。短决定时限不能被宣传为解决了网络延迟。

### F4 截止优先与未成交事项

总截止时先封盘，再处理结束事实；不再掷骰、付新的落点费用、领起点补给、加回合结束开支或打开下一个决定。

| 正在处理的事项 | 封盘后果 |
|---|---|
| 城市/机场购买、建设、拆房、抵押、股票订单 | 截止前已提交结果保留；仅草稿或未提交内容不执行 |
| 股份转让 | 已成交的现金和股份保留；等待接收方确认的转让取消，双方原资产保持 |
| 普通出售拍卖、自救出售拍卖、直接出售 | 未成交取消；城市保留卖方已成立的产权、房级、支出及股份关系，不补银行回购款 |
| 无主城购买后的拍卖 | 未成交取消，仍为无主，不因最高报价转移产权或扣钱 |
| 正在选择机遇或后续路线 | 尚未整体生效的选择取消，旧路线保持，不补一次性奖励；已完成阶段的结果保留 |
| 扣费后自救 | 保留已扣费用、当前负现金和剩余资产；不自动卖资产，不仅因封盘判破产 |
| 已确认破产的后续拍卖 | 依F5完成既有破产资产收尾，破产不撤销 |

取消不是退回此前已成立的费用，也不是把出价当成交。结束页和记录列出取消事项及原因。

### F5 已确认破产的资产收尾

玩家在截止前已按规则确认破产，出局和已发生的救济、成交保持。其尚未成交的城市拍卖及后续队列停止；这些仍属于已破产者的城市直接归银行，拆除房屋，不发卖方回购款。

有关城市先按现有清算规则派发存活股东应得的待分红，再按经营报价50%清偿存活持股，清除股份和经营状态；未售股份收益按既有归银行规则处理。不把残留股份按正常持续经营报价计入存活玩家排名。只处理已确认破产者的残留城市，不把自救中的存活卖方当作破产。

收尾不能启动新的拍卖，不重复派息、救济或清算。此前已经成交给存活者的城市不再收走，破产玩家名次和出局时点保留。

### F6 派息与净资产

完成F4/F5的取消和收尾后，只结清已有城市待分红；不推进资讯、房屋、租金或新的经营轮次。原股息机遇按既有合法条件和剩余额度处理，不增加额外终局奖励。派息只执行一次。

所有存活玩家使用同一份封盘后状态计算：

**净资产 = 现金 + 城市标准价值 + 机场标准价值 + 派息后持股报价价值 − 抵押本金 − 累计抵押利息。**

- 现金可以为负；净资产可以为负，不自动改为零或抹掉债务。
- 城市标准价值按地价加各级标准建设价值，机场每座15000。
- 股票按实际持股乘派息后的经营报价；未发行股份不当成玩家库存。
- 抵押本金和累计利息分别扣除；抵押城市不再额外减半价值，避免同一债务扣两次。
- 当前已收租及已派息现金不再重复计入待分红；城主的未售股份及取整零头按原结算处理。

延续标准资产估值以保持规则简单；优惠建设支出小于标准增加价值的差异须在有限案例中记录。该差异不被隐藏成现金利润，也不在本轮擅自改成按实际建设支出计分。

### F7 胜负、提前结束与同分

30分钟封盘时，存活玩家按净资产降序排名；净资产完全相同则并列，最高并列为共同第一。不以座位、连接速度、最后操作者或未定义的指标打破同分。

出局玩家排在存活者之后，沿用原出局先后规则。若截止前已确认只剩一位存活玩家，快速模式提前结束，该玩家获胜；仍待处理的破产资产按F5收尾，不再等待多轮拍卖。普通模式原胜负与破产拍卖推进不因此改变。

房主解散、无人清理等原房间结束仍保留，明确实际结束原因；不得把解散或清理写成正常30分钟完赛。快速局的存活者在这些提前房间结束中按相同净资产口径展示，保留原结束性质。

### F8 接入已批准的快速机遇节奏

初始公共机遇分别于开局、第5、第10分钟标记可用，在安全交接处按序进入；原普通条件不用于快速局。第15、第22分钟为存活者各生成一次个人后续机会，三个初始阶段完成后在本人合法掷骰前领取。

到时标记不打断已有必要流程。后续一回合最多处理一份；第28分钟不再打开新后续机会，尚未打开的失效；此前已打开的受自身时限及30分钟总截止约束。总截止优先于初始阶段、后续确认及一次性奖励。

沿用已批准的三项持有上限、替换/跳过、隐私、无后续换组及使用/领奖历史。环球资讯仍按原完整轮次运行，本轮不同时改成分钟制。

### F9 回执、重连与记录一致

动作、个人超时和总截止相邻发生时，服务端最终只提交一种结果。截止时及之后新动作拒绝；截止前已经完成并提交的动作保留。原请求的结果查询仍能核对成功或失败，不能因终局把已成功的动作误显示为未执行。

迟到回执、重复请求、重复截止通知和重连不重开窗口、不再派息、不恢复取消交易，也不恢复游戏。在线玩家收到同一结束结果，运行中的房间重连能看到该结果。记录含模式、开始/结束时间、结束原因、净资产组成、并列结果、已取消事项与必要清算。

### F10 三端资产与结束解释

快速局资产概览明确显示用于排名的净资产；可以继续查看原资产总值，但两者标签不同。明细列出现金、城市、机场、股票、抵押本金和利息，成交前仍看实际现金，净资产不能被当成可支付余额。

PC、平板、手机横屏均看见总时限、个人余时、结束预告和结果；待确认动作与已成交反馈保留。封盘时旧弹窗不能继续提供可成交入口，结果页能查看取消原因、明细和并列；无需玩家额外点“结束游戏”。

### F11 普通、旧局与帮助兼容

普通模式保持现有初始机遇条件、决定时限、经济数值和最后存活者获胜。旧已开始对局不在中途加入总时钟、改成净资产胜负或迁移成长时点。

房间模式说明、规则速查、对局界面和终局记录对应本局规则。旧记录缺少模式、债务快照或净资产时说明数据未记录，不伪造新的排名。静态页面升级后不因旧缓存开放错误入口。

## 非功能需求

- **N1 正确性：** 服务端统一判定总截止、提交与结算；一份结束状态、一份有效结算。任一步失败不得留下部分资产转移或重复收款，能核对原请求结果。
- **N2 维护与兼容：** 沿用现有服务端、原生前端和Node20运行环境，不增加框架或运行时依赖；既有游戏价格、骰子、股票比例和优惠上限保持，限时与快速阶段是明确例外。
- **N3 可用性：** 三端保留清楚文字、触控和键盘入口，关键按钮至少44×44 CSS像素，缩放后计时和结果可读；降低视觉动画时状态处理仍一致。
- **N4 有限验证：** 使用可控制的时间、指定局面和少量真实联机流程；不靠每次等待真实30分钟，不运行大量完整对局或胜率矩阵。功能正确和时间结束不等于总体胜率平衡。

## 不做的事

- 不在本项目加入经营任务、股票经营说明、额外主动卡片、地图机关或修改首圈购置门槛；这些按独立项目处理。
- 不提高租金、削减起点补给、修改远航开支或机遇奖励来强迫半小时内破产。
- 不改变普通模式，不迁移旧局或重写历史结果。
- 不在快速核心中暗中启用离线自动投资；保守离线推进按独立规格交付。
- 不新增账号、数据库对局存档、跨服务器重启恢复，不更换Render套餐或供应商。
- 不把实现或本地验收当成已推送/已部署；部署按实际授权和结果登记。

### 净资产复算样例

结清收益后的状态：现金100000，城市标准价值34000，机场15000，派息后股票价值8800，抵押本金10000，累计利息1800。

净资产 = 100000 + 34000 + 15000 + 8800 − 10000 − 1800 = **146000**。
