# 手机横屏居中台账 Spec

## 背景与目标

台账在地图右上角，且高度受短屏幕限制，信息挤在短卡片里。用户要求放大台账，形状接近中央地图矩形，并置于地图中心。

## 功能需求

- F1：手机横屏台账的宽、高均采用中央地图的 72%，中心与地图中心重合；四周留出地图，不遮挡外围地块。
- F2：台账内原有资产、机遇、资讯与回合信息完整保留，内容过多时内部滚动；棋盘继续独立滚动，按钮保持可操作。
- F3：旋转/尺寸变化后更新台账比例与位置，回到 PC 时恢复原台账布局。

## 非功能需求与边界

沿用现有真实状态、操作和本地地图，不修改经营/交易规则或计时；手机仍仅横屏游玩。静态缓存同步升级，不刷新进行中的对局。本轮仍禁止推送。采用有限浏览器场景，不跑整局。

## 验收标准

- AC1 / F1：932×430、844×390、844×280、568×320 模拟手机视口台账中心与地图中心误差小于 1px，宽高比例为 72%，位于内部矩形。
- AC2 / F2：长内容可以滑动到底部并查看资讯和回合；原资产入口、地块详情可触屏打开；外围42格及文字保留，无整页横向溢出。
- AC3 / F3：连续变更尺寸与切换 PC 后位置和尺寸正确，缓存升级通过。

## 审查

2026-10-13：按用户文档自审授权审核通过；F1–F3 均有可观察验收，72% 同比例缩放明确符合矩形形状要求。
