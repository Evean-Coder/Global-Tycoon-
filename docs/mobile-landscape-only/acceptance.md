# 手机仅横屏游玩验收

2026-10-13。实现完成、四份开发文档及验收自审完成。本轮承接用户「做完先别自动推送」指示，仅本地提交，不推送、不部署；当前发布暂停也记录在项目协作约定中。

## 交付
- 删除6×7位置算法、compactLayout、compact-game/short-game样式及竖屏信息标签、地图/资产槽、更多按钮和操作Dock；手机没有另一套可玩竖屏布局。
- 手机进入对局尝试方向锁定；失败、缺失、2秒无结果均显示手动说明。点击按钮可尝试全屏后锁定；iPhone等无法自动锁定的环境仍可开启自动旋转手动横放。
- 竖屏提示是body直接子节点，优先级高于所有游戏弹窗。背后界面inert、焦点锁在提示内，Escape及遮罩无法关闭，动作入口另有守卫。转回竖屏立即阻挡，实际横屏才解除。
- 房主竖屏点击开始先保存单次意图，横屏后才正式开局；刷新/重连收到对局状态后先显示提示。旋转不清草稿、不提交动作、不重置时限。
- 保留手机横屏左右分区和等比铺满地图；PC、平板布局仍可用。manifest声明landscape，资源版本20261013-landscape-only-v1，缓存global-tycoon-v28-landscape-only，新方向模块参与缓存。

## 实际限制
Windows Edge Chromium模拟触控视口已测；自动锁定成功分支采用受控API模拟，实际系统自动转屏及实体iPhone/Android未实测。网页不能打开系统自动旋转设置，也不能保证每种浏览器都允许锁定；因此手动提示始终按实际方向决定放行。

房主正式开局前的旋转不消耗对局时间；客人进入已有对局及对局中转回竖屏时，现有服务器决定时限、总时限照常进行。方向提示仅控制本地游玩，不修改联机暂停规则。
