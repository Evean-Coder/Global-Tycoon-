# 主动经营次数与提示 Spec

日期：2026-10-11。状态：2026-10-11用户统一批准开发；实现与实际验证见 acceptance.md。

## 背景与目标

用户记忆中的“每圈一次”与当前规则不同：主动经营是每个本人正常回合掷骰前最多成功一项；促销、主动买股和远程施工优惠另有每圈额度。现有入口主要位于台账内，提示不够突出。本轮让玩家在掷骰前清楚看到机会、已用状态与每圈额度，不改次数或玩法。

## 功能需求

- F1 正常本人掷骰前，在掷骰操作附近显示主动经营状态及可操作入口，明确“本回合可经营1项，也可直接掷骰”。无需先打开资产台账。
- F2 有机会且至少一个项目可执行时，入口使用清晰文字、强调边框/图标和一致主题色；成功后显示“本回合已经营，下次正常回合可用”。打开、取消、失败不显示为已用，不多次弹出提醒。
- F3 若次数未用但所有项目当前不可执行，显示“本回合未经营，当前无可执行项目”，可查看具体原因；其他人回合、特殊决定、结束和未启用规则分别给出准确状态，不误显示“已经营”。
- F4 经营面板将两类限制分开：每回合共用机会1项；每圈促销1次、主动买股4股/同城2股。远程施工机遇仅优惠每圈首次主动建设，不能写成建设本身每圈一次。
- F5 次数只随真实个人回合推进，圈额度只随本人真实起点结算更新；卖出、转让、刷新、返回和重连不恢复额度。三端显示同一真实状态，旧局未启用不显示虚假机会。
- F6 规则速查与台账入口保持一致，支持直接查看次数/额度说明；直接掷骰沿原流程，不新增确认或阻挡。

## 非功能需求与边界

- N1 新增提示只读，原服务端报价与资格为准；沿用现有技术栈、Socket动作和倒计时，不增加依赖。
- N2 三端提示不遮挡掷骰、计时、棋盘或操作按钮；触屏/键盘均能进入，不能只靠颜色/闪烁表达。
- N3 只读取本人额度，不公开私人报价；有限固定状态及少量浏览器验证，不跑大量完整对局。

不把规则改成每圈一次、不加次数或奖励、不自动经营、不增加系统弹窗/强制跳过确认、不改变经济数值、AI策略、回合推进和快速总时长。

## 验收标准

| 编号 | 对应 | 可观察结果 |
|---|---|---|
| AC1 | F1/F2 | 普通/快速本人正常待掷骰有合法项目时，掷骰旁直接看到“可经营1项”及可操作按钮 |
| AC2 | F2 | 打开/取消/失败后仍未用；任一经营成功后显示已用，不能成功第二项；下一本人正常回合恢复，即使尚未绕完一圈 |
| AC3 | F3 | 未用但无合法项目、非本人回合、特殊阶段、终局、旧局分别显示准确状态；不会把暂不可用误标为已用 |
| AC4 | F4/F5 | 同一圈不同回合可经营不同项目；促销已用仍可合法建设/买股；买股总4股或同城2股耗尽与共用回合机会分开提示 |
| AC5 | F4/F5 | 有/无远程施工机遇及优惠已用/未用显示准确；已用优惠不误禁用后续合法主动建设；真实过起点更新圈额度，不凭位置或完整轮数重置 |
| AC6 | F5/F6 | 返回、重连、卖出和转让后次数保持；直接掷骰只发原请求，未用机会不累积、不增加期限 |
| AC7 | F1/F6/N2 | PC、平板、手机均看见状态及入口；可键盘/触屏操作、可查看规则，按钮与计时不遮挡，无整页横向溢出 |
| AC8 | F6/N1/N3 | 规则文案与实际许可一致，新增查看无资金/次数/状态变化；发布文档与缓存同步，验收据实记录 |

## 自审

F1→AC1/AC7；F2→AC1/AC2；F3→AC3；F4→AC4/AC5；F5→AC4–AC6；F6→AC6–AC8。保留既有“每回合成功一项”规则，仅加强可发现性与解释。
