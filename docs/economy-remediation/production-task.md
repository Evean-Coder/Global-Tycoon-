## 执行约束

每项为聚焦修改或验证单元，目标2–5分钟；遇到实际缺陷先修复该项并记录，不在失败后增加对照批次。按依赖顺序执行，验证后才勾选。相关任务组完成后选择性提交，不纳入无关未跟踪文件。
