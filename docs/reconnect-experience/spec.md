# 离线推进 Spec

2026-10-14。用户“现在做”授权实施；四份文档按既有授权自审，不推送。替代旧提案过期的30秒机遇/有时限自救描述。

F1 非必要决策者离线时，在线者继续自己的回合/交易，轻提示名单。
F2 轮到离线者普通决定最多等待20秒，且不超过原期限；同一决定反复断线不补等待，原正常时限不因查看或单人离线暂停。认证重连结束连续托管，未耗尽的同决定等待预算保持。
F3 等待结束后正常回合放弃经营并掷骰；购买、建造、募资、飞行、股票、转让、拍卖和受让保守放弃，冻结不缴费，监狱掷骰。持续离线后续决定直接默认，不自动抵押/卖资产或免债。
F4 同步机遇只给离线未提交者按其当前最左项提交，在线者保留原60秒；已提交不重选，私有候选不公开。
F5 自救保持最新无独立时限规则：离线自救者等待本人重连凑款或主动放弃，不自动破产。全真人离线停止无人推进，沿用闲置清理；快速30分钟继续并封盘。无人期间不执行默认，既有20秒等待不重新发放。
F6 新局disconnect-v1，旧局维持全局暂停；重连、超时及动作竞争只生效一次，提示原因，正常在线期限、钱款及AI规则不变。

N1 服务端统一处理，沿原请求/校验/候选复制提交，有限测试无新依赖。N2 三端键盘/触屏提示不挡在线者，版本/记录/缓存同步。
AC1/F1 两至四人非当前掉线不暂停在线动作。AC2/F2 20秒/短原期限/重连重断不补时。AC3/F3 各默认无主动财产处置、连续失联不重复等待。AC4/F4 离线个人选择不缩在线60秒。AC5/F5 自救无限、全员停机和快速封盘。AC6/F6 重复/竞争/旧局/AI/隐私/界面真实验证。
