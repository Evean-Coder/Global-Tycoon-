# 股票投资 v2 验收记录

2026-10-15。用户“是的，开发吧”批准四份文档及正式开发，随后要求继续未完成开发。本轮26项任务已实施，36项清单在下述有限环境完成验证。

## 实际交付

- 新局独立版本 `stock-investment-v2`：每城10份、城主2份、外部股东4份；旧20股局不迁移。
- 标准地产建设资产12%与实际经营/抵押系数报价；租金20%与银行40%即时分配，H4只奖励租金来源，原H6保留。
- 固定份额来源账本、FIFO部分回收、90%普通/强制退出、50%清算；玩家高价倒手不抬高银行来源上限。资产及快速封盘使用真实银行回收额。
- 掷骰前2股1城、起点4股3城各2的独立累计额度；普通股票交易不耗经营机会。新局经营保留订单和远程建设，移除重复主动买股及30%临时奖。
- 玩家单城1–4股协商收购/出售、卖方2%手续费、非阻塞邀请；20秒/原决定/快速封盘取最早期限，离线、相关报价变化和离开发起窗口取消。
- 资产、银行、自救、购地/机场/建房募资共用实际银行回收金额；股票卡显示经营、持股、理论股息依据，持仓显示真实现金收支。
- AI采用公开信息评估股息、现金储备和退出损失，能在非本人回合回复报价。普通股票评估最多24步、未来现金每步折现0.98；快速模式受实际剩余时间约束。长期预测不保证收益。
- 新能力声明、缓存v43与资源20261015-stock-investment同步；旧客户端不能开启或操作新股票局，升级不强刷在玩旧局。
