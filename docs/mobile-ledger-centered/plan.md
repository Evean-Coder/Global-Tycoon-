# 手机横屏居中台账 Plan

## 架构与接口

复用 `placeBoardSurfaces()` 的中央地图 left/top/width/height。横屏时 `width/height` 分别乘 0.72，left/top 分别加地图宽高的 0.14，right 设 auto、maxHeight 设 none。尺寸取自实际地块，不受 `boardWrap.clientHeight` 限制。PC 分支保持原台账样式，原布局切换已清理内联 height 等属性。

## 样式和交互

移除手机台账 48% 最大宽度；维持单个浮层的纵向滚动，台账直属子项不收缩，避免资讯/回合被压扁。触摸滚动限制在台账，棋盘外围滚动沿用现有实现。原读数、内容入口、事件与 Socket 不变。

## 数据流与覆盖

原对局渲染 → 原布局监听 → 地图边界 → 横屏居中同形台账（F1/F3） → 原台账渲染和内部滚动（F2）。资源更新到 v34。测试实际双人开局，再注入有限长内容状态，触屏查看资产和地块，核验比例、滚动、PC恢复及缓存。
