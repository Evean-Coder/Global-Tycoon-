# 银行抵押列表布局 Spec

2026-10-12，沿用用户文档自审和全部整改开发授权。

## 背景与目标

玩家截图中抵押城市被挤成细缝，名称、金额与按钮无法查看。修复布局，保持原交易规则。

## 需求

- F1 每城独立显示完整名称、可抵押金额与按钮，长名换行。
- F2 抵押、赎回、持股保持自然高度，银行仅一个内容滚动区。
- F3 同一决定更新保留浏览位置、建房卖股草稿，原动作及强制阶段继续可用。
- N1 沿用原生前端，无新增依赖；按钮至少44px高，窄屏无横向溢出。
- N2 有限受控状态与必要回归，记录真实证据。

## 边界

不修改抵押上限、价格、利息、权限、股票或倒计时，不修改其他资产列表，不部署。

## 验收

- AC1 三端及低高度横屏每行名称/金额完整，按钮至少44px高（F1/N1）。
- AC2 多城/多股/已抵押同时存在，外层滚动可浏览各节和关闭，无列表折叠或横溢（F2）。
- AC3 实际抵押/赎回成功且不延时；更新保留位置、建房草稿及返回，强制决定替换银行（F3）。
- AC4 缓存升级、相关浏览器回归及lint通过（N2）。
