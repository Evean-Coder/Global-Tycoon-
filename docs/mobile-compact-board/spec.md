# 手机横屏完整棋盘 Spec

日期：2026-10-14。四份文档依用户授权自审，用户已批准开发。随后明确纠正：保持原有布局，通过缩小地图格容纳全图。本修订以最新指示为准，取消棋盘重排与常驻面板隐藏方案。

## 背景与目标

目前手机横屏采用与电脑相同的12列、11行棋盘，并占用右侧信息区；地块显示国家、全名、价格、房屋、抵押与持有者，因此需要滑动才能看完整42格。目标是在默认缩放的手机横屏中看完整路线，通过点击阅读详细经营信息，同时协调其他区域。

## 功能需求

- F1 手机横屏一次显示完整42格环形棋盘，保留0–41编号与顺时针相邻行走关系。默认不依赖横向/纵向滚动找格子；保持原12列×11行、全部格子位置和0/11/21/32四角不变，不改变编号、类型、落点或游戏效果。
- F2 地块常显序号、城市短名/特殊格名称、明确类型图标。地产用房子，机场用飞机；起点、机会、休闲、监狱、南北极各有区别。国家、价格、房级、抵押、城主姓名和股票数据移入详情。长名用一致明确的短名，详情显示官方全名；不省略成无法分辨的省略号。
- F3 自有/他人城市及机场使用真实持有者的玩家颜色标记；无主保持中性。色条与淡底保持文字对比，不用整块饱和色覆盖文字。产权颜色与玩家棋子位置分别表达；提供颜色/席位图例及持有者文字详情，不能把色组当产权。
- F4 点击任何地块可看真实完整信息。城市继续显示国家/城市、持有者、价格、房级、抵押、租金及可见股票报价，机场显示全名、归属、价格和费用；特殊格说明其效果。查看只读，不提交购买/经营、不重置期限，不泄漏其他玩家私人任务或候选。
- F5 手机整页协调缩小：顶部一行状态，底部保留“掷骰→主动经营→资产→银行”的顺序；股票市场、任务、玩家、事件和规则保留可访问入口。保留原中央左资讯、右资产台账和棋盘右侧玩家/事件栏，压缩字体、内边距与栏目宽度，资料内部滚动；额外“更多”只用于放大阅读，不取代常驻面板；资讯、决定/整局期限仍能及时察觉。
- F6 中央世界地图铺满环形棋盘内部矩形。棋子真实位置和原动画速度保留；多人同格显示可识别标记/人数，并可在地块详情确认同格玩家。转屏、重连与广播不会改变落点、资金、股票草稿或重复弹出决定。
- F7 原横屏门禁、强制决定优先级、经营放弃/关闭、股票/自救操作、读展开与帮助定位继续生效；PC及常规平板保持当前详细布局。系统放大需要更多空间时保留完整资料和放大查看能力，不以隐藏信息维持截图。

## 非功能需求

N1 沿现有技术栈和真实服务端状态；不新增服务端事件、规则版本、付费素材或运行时依赖。图片继续本地加载。
N2 默认布局目标视口为568×280、568×320、844×280、844×390、932×430；以实际可用内容尺寸扣除安全区。保留11行的短屏中，地块至少32像素宽、15像素高；短名最窄视口8像素，844宽约10.1像素、较宽视口11像素。主要操作/菜单不小于44像素高。该取舍来自用户坚持原布局并要求全图；提供可主动选择的放大查看，不能把小地块描述为舒适的大触控目标。更小可用空间和系统放大提供地图放大查看回退，不能宣称任意尺寸都完整可读。
N3 触屏/键盘可打开和关闭详情，图标有文字含义，不仅靠颜色。有限固定场景与浏览器模拟验收，真机未实际验证不得写通过；不跑大量完整对局。

## 范围边界

本轮仅手机地图展示和配套信息布局；不改42格数据、编号、价格、购买时机、移动速度、机遇规则和联机协议。城市简称与机场简称只改变展示。电脑和常规平板不改成简化棋盘。

## 验收标准

AC1/F1：目标视口两模式均一次显示42格，无默认棋盘滚动；编号唯一，相邻格含41→0连续，真实操作栏不遮挡。
AC2/F2：所有格有可读编号/短名/类型图标，最长名和机场能区分，细节不以省略号替代。
AC3/F3：四位玩家产权、无主、转让、银行收回和抵押状态颜色正确；图例/详情能用文字识别，棋子颜色不被误当产权。
AC4/F4：全部类别可点，详细数据与实际状态一致，只读查看不改资金、期限、草稿或权限。
AC5/F5：顶栏/主操作/菜单/资讯/任务/玩家/事件入口可操作，两种期限可见，正常及离线/自救提示不会挤掉棋盘。
AC6/F6：完整中央地图无空缝，1–4人同格、移动/转屏/状态更新落点正确，旧动画速度与草稿保留。
AC7/F7：最高横屏提示、机遇、经营、股票、银行、自救、规则和读状态不回归；电脑/平板及必要缩放回退可读。
