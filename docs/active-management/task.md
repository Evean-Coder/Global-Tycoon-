# 三类主动经营 Tasks

日期：2026-10-10。状态：用户已于本轮最终确认开发；当前实现与实际验证见 ../gameplay-improvements/progress.md。本轮任务实现及限定验收已完成，逐项证据见总验收索引。

用户在整份Plan审批请求后回复“继续”，记录整体批准。以下任务只覆盖主动经营，不实现置业扶持或独立规则提示。

## 文件与执行约定

新增经营模块、指定状态/收益测试及有限联机用例；修改文件列在各任务中。文件范围中的现有入口须在T1明确实际函数位置，不另建并行规则引擎。保护已有工作区改动，原起点窗口、旧局、落点操作和时钟均为回归对象。

按依赖执行；每任务完成记录实际验证结果，失败先修复。任务涵盖单一职责，遇到跨多个产权或租金出口时按出口分别记录完成与证据。运行项目指定测试时使用Node20及现有测试工具，不默认调用大规模balance脚本。
