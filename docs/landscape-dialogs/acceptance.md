# 手机横屏弹窗整体整改验收

2026-10-13。用户五张截图对应的股票、机遇、经营、自救问题已在本地整改，同时覆盖银行、资产及其他通用窗口。沿用文档自审授权，四份独立文档齐备后实施。未推送或部署Render；线上截图中的旧布局不会因本地提交自动更新。

## 改动

- 股票：左侧独立滚动城市列表，右侧资金/额度/草稿与四个交易按钮；规则放标题栏，首城买卖可触达，节点和滚动锚点保留。
- 机遇：横屏三卡并列，紧凑标题和状态，方向与名称同一行；完整长描述可触屏/键盘滚动，三项选择按钮始终可见。后续路线沿用正文滚动与固定操作。
- 通用窗口：标题不压缩，正文的内容行保持自然高度，只正文滚动。横屏的城市操作分为独立卡片，按钮至少44px。
- 自救：当前缺口和现金并列，原欠款、债务来源与费用说明可展开；抵押/拆房/出售/拍卖入口保留。电脑/平板默认展开说明。
- 经营：标题与规则同排，主界面固定底部左右按钮不变，子窗口移除重复主说明的视觉占位，首个项目确认按钮在短横屏完整显示。
- 限制浏览器额外自动放大正文，保留系统缩放；资源`20261013-landscape-dialogs-v1`、PWA缓存`global-tycoon-v30-landscape-dialogs`。服务端价格、规则和时限未修改。

## 问题及修正记录

首次新用例3组中机遇阅读区只有14px，压缩顶部说明并合并卡片名称/方向后通过。截图复核发现旧的order把股票侧栏排到了左边，已修正并增加左右位置与宽度断言。一次并发回归的980×400测量读到上一个视口的动态高度；测试改为等待两个渲染帧后测量，最终四种尺寸全部通过。上述未通过日志原样保留，仅清理行尾空白。
