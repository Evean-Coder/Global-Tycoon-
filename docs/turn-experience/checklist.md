- [ ] C1（AC1）：固定有可负担订单局，直接掷骰成功；本回合未用经营随动作放弃，骰子及移动只发生一次。（引擎固定场景）
- [ ] C2（AC1）：同一掷骰请求重送、旧决定请求、验证失败及跨封盘提交均无部分放弃／扣钱／重复移动。（动作与双Socket）
- [ ] C3（AC2）：关闭查看后经营机会仍在，可以手动经营或直接掷骰；显式放弃后本回合不可再经营。（浏览器实际按钮）
- [ ] C4（AC2、AC14）：成功经营一项后可掷骰，第二项拒绝且不产生资金／次数变化。（动作及界面）
- [ ] C5（AC3）：首圈无资产、全部无项目、非本人回合、入狱／冻结均无经营误弹。（固定状态）
- [ ] C6（AC3）：有项目仅安全时点自动显示一次；关闭、股票成交、重复状态、同回合重连／页面重开不重弹。（浏览器和重连）
- [ ] C7（AC4）：资产／资讯／帮助、强制选择及方向提示正在显示时不叠经营；关闭后若仍同回合才提醒，已掷骰则不补弹。（窗口交接）
- [ ] C8（AC5）：三类型卡可选数与真实原因正确；目标费用、现金、条件／风险均可见，报价变化必须重新核对确认。（三路线固定目标）
