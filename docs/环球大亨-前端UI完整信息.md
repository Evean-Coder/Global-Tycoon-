# 环球大亨前端 UI 参考

> 更新：2026-10-09。本文描述当前 `public/` 实现，包含后期费用显示及手机/开局/股票返回整改。最新限定验证见[手机复验](gameplay-usability/mobile-acceptance.md)。玩家规则见 [rules.md](../rules.md)，服务端契约见 [开发参考](环球大亨-权威开发文档.md)，完成程度和测试范围见 [项目现状](项目现状.md)。

后期费用来自服务端公开状态：资讯栏显示当前完整轮、费用及提前两轮预告，资讯未发布时也保留；资产自救显示债务来源，记录回放单列“远航开支（支出）”。大厅规则使用页面经济版本，对局规则以当前状态为准，旧局不显示新费用；没有新增缴费操作或Socket事件。操作区可用高度按实际视口像素重算，三端与真实200%缩放证据见[费用验收](economy-remediation/production-acceptance.md)。

## 1. 设计基准

当前视觉采用已确认的日光海面蓝、暖白卡片及少量金色。正式对局中央显示世界地图，地图上层放本人真实资产卡；42格外圈是棋盘，棋子独立覆盖。离线demo用于视觉确认，不是运行代码、实际金额或游戏规则来源。

| CSS令牌 | 当前值 | 用途 |
|---|---|---|
| `--bg / --bg2` | `#126b9f / #075781` | 海蓝背景与层次 |
| `--card / --card2 / --card3` | `#fffdf8 / #f5efe3 / #e8ddca` | 暖白卡片、次级区域 |
| `--gold / --gold2` | `#c99c49 / #b27b31` | 主操作与少量装饰 |
| `--title / --text / --muted` | `#0b354b / #17394a / #567380` | 标题、正文、辅助文字 |
| `--danger / --success` | `#b34d4a / #328769` | 风险和成功反馈 |

标题使用Georgia/中文宋体等系统衬线回退，正文为系统无衬线，金额使用等宽数字。无外部字体/CDN运行依赖。

本地素材为 [海面](../public/assets/ocean-surface.png) 和 [世界地图](../public/assets/world-map-ocean.png)；CSS提供纯色后备。图片来自项目正式静态目录，不能依赖开发机绝对图片路径或远程临时URL。

## 2. 页面结构

原生单页，通过视图隐藏/显示切换；当前DOM见 [index.html](../public/index.html)。

| 入口/节点 | 内容与操作 |
|---|---|
| `#view-lobby` | 昵称、创建房间、六位码加入；连接状态影响按钮可用性 |
| `#view-room` | 房间码及复制、玩家名单、房主开始、退出 |
| `#view-game` | 暂停横幅、资讯、棋盘资产、侧栏与操作栏；手机短横屏内容区独立滚动 |
| `#waitBanner` | 存活玩家断线等暂停信息 |
| `#newsBar` | 环球资讯、剩余完整轮、下一条预告 |
| `#boardWrap / #boardScale / #board` | 42格棋盘与世界地图背景 |
| `#pieces` | 玩家棋子，按地块和容器实际尺寸定位 |
| `#ledger / #ledgerBody` | 本人总资产、现金、地产、机场、持股与完整资产入口 |
| `#sidePlayer / #sideOthers / #log` | 本人状态、其他玩家、公开事件，可展开/滚动 |
| `#actionBar` | 骰子、回合、掷骰、资产、银行、原结束入口与倒计时 |
| `#connectionStatus` | 连接、身份恢复、开局处理中及失败/未确认原因 |
| `#btnResumeStock / #btnStockAssets` | 当前股票决定恢复买卖面板 / 从股票面板查看资产 |

侧栏保留股票市场、认输、房主解散入口。界面使用“环球资讯”“经营机遇”“已选机遇”等自然名称，产品不展示内部功能组合标签。

资产卡、排名与记录用服务端统一资产摘要；现金和不可立即花费的资产应区分。地块/资产查看是只读；新增详情不能发送新的游戏动作。

## 3. 三端布局

| 区间 | 实际布局 |
|---|---|
| 大于1080px | 棋盘优先、侧栏并排；1320px以下侧栏缩窄；地图上层保留资产卡 |
| 721–1080px | 棋盘在上、信息在下；1080px以下侧栏三列，900px以下两列；操作栏为信息与按钮两行 |
| 不超过720px | 12列×11行外圈完整棋盘，宽度适应屏幕；资产卡精简，保留完整入口；侧栏重排，页面允许纵向滚动 |
| 不超过375px | 更小字号和间距，保留可点地块、详情与关键操作 |
| 横屏且宽≤1200px、高≤500px | 紧凑标题/资讯、独立纵向滚动内容、操作栏分行占位；不会由横屏宽度误用高屏平板布局 |

手机格内文字是总览，完整说明通过点按查看。完整棋盘“可在一屏宽内呈现”不等于整个页面强制一屏高；资产详情、玩家和长事件可纵向展开/滚动。

普通布局操作栏固定在底部，客户端根据实际高度给页面留白；手机短横屏操作栏占独立布局行，内容区域滚动到各地块时不被覆盖。资讯栏、系统缩放和长按钮不应遮挡地块或最后一个入口。棋盘ResizeObserver及窗口变化重新定位棋子，不能按固定像素缓存位置。大厅与房间横屏提示位于开局操作前，竖屏仍可正常创建/加入。

## 4. 渲染与原交互

[client.js](../public/client.js) 保留 `renderBoard`、`renderPieces`、`renderLedger`、`renderSide`、`renderActionBar`、`renderPending`，并增加 `renderNews`、`renderOpportunities`。收到状态后保留原动画/状态顺序，减少动画设置跳过视觉动画，不跳过规则状态更新。

- 城市地块沿原城市详情，非城市地块展示对应资料；使用原生按钮供触控和键盘访问。
- 资产卡和操作栏进入原完整资产视图；城市行可查看详情及合法银行操作。
- `sendAction` 封装对局/请求/决定/本人版本；费用携带报价版本，股票携带窗口、报价与经营身份。
- 错误由回执/toast展示。股票旧报价失败保留草稿，提示查看报价后重新确认；成功回执后再结束窗口。
- 正式UI确认股票交易后会发送 `stock_done` 结束窗口。服务器仍按整个窗口累计买入额度，不能用请求拆分、卖出或转让重置额度。
- 原 `#btnEndTurn` 当前仍绑定掷骰处理，不应把其文案推断成任意跳过当前阶段的接口。
- 认输和解散使用确认提示；按钮是否可用与服务器资格一致，不能仅凭UI隐藏认为安全。
- 连接存储与认证恢复保留原席位；同名字符串不能替代重连令牌。
- 创建/加入/开始使用请求锁、10秒确认等待和错误展示，断线时不缓存新请求；创建/加入可由匹配房间状态确认。受限浏览器存储不阻断页面，重连凭据无法保存时明确提示。
- 股票市场进入转让，未提交返回原市场并保留同窗草稿；资产来源则回资产页，通过继续买卖入口恢复市场。查看/返回不提交动作、不延时；过期返回不覆盖新决定。

## 5. 弹窗和选择

| 节点/类型 | 用途 |
|---|---|
| `#modal` | 通用落点、购买、建设、募资、自救、机场/监狱/极地、拍卖/出售、资产、结算等 |
| `#stockModal` | 市场、买卖草稿、金额汇总、转让入口 |
| `#choiceModal` | 三项候选、全员进度、共享计时、一次换组、规则、房主解散 |
| `#rulesModal` | 滚动规则速查，可从机遇阶段打开 |
| `#toast` | 错误和短反馈 |

选择候选只给本人，提交后保留阶段等待展示，不能绕过强制选择掷骰。统一生效后显示已选机遇。阶段结束/终局应清理旧弹窗，避免被过期票据覆盖。

费用说明显示标准金额、资讯/机遇贡献与实际金额；远程施工逐城展示合法性和费用。股票显示经营价值、每股待分红、涨跌原因、抵押提示、上次分红及剩余额度。

弹窗有最大高度与内部滚动，手机卡片竖排，关键机遇按钮至少44px；其他控件按现有实现检查实际大小，不承诺全部42个小地块都有44px。统一处理焦点进入、Tab限制和关闭恢复，长文案不能挤掉按钮。系统viewport允许缩放；减少动画仍完成所有状态处理。

## 6. 图片与PWA更新

当前缓存 `global-tycoon-v8-mobile`，HTML脚本/样式版本 `20261009-mobile-r2`。`sw.js` 缓存页面、客户端/样式、公开规则目录、Socket.IO客户端脚本、两张PNG、manifest与图标。

HTML网络优先，静态资源缓存优先并使用版本URL更新；Socket握手和轮询不缓存。离线静态脚本失败不得回退成HTML。离线只展示缓存外壳，不提供离线联机；PWA注册依赖HTTPS/localhost安全上下文。

修改正式前端须同时核对静态版本与缓存清单。demo中曾发生图片路径不显示，正式实现已使用同源本地文件；测试还覆盖图片阻断后的后备可用性。
