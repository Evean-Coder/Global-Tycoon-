- [x] 对局中央世界地图和页面海面纹理实际绘制出来，地块色组仍清楚可辨。（验证：运行服务并在 PC、平板、手机打开页面，检查两张图片请求返回 200 且截图能看到纹理。） **证据：C02**

## PC 对局（AC2）

- [x] 42 格顺时针闭环完整可见，格内名称可读，地块尺寸相对旧版有可测量增大。（验证：在同一 PC 视口记录改版前后地块外框尺寸，并核对 42 格数量与顺序。） **证据：C04**
- [x] 本人资产卡位于世界地图上层，完整显示资产概览，且不压住外围地块；其他玩家与事件信息可见。（验证：1366×768 和 1440×900 截图，并检查地图卡、地块及侧栏的外框不冲突。） **证据：C05**
- [x] 固定操作栏不会遮挡底排地块或侧栏末尾操作。（验证：PC 页面滚动到顶部和底部，检查地块与按钮的外框及实际点按。） **证据：C06**

## 平板与手机（AC3、AC4、AC5）

- [x] 320px、375px、430px 手机视口中，42 格棋盘在一屏宽内完整呈现，无棋盘内部横向滑动或整页横向溢出。（验证：记录各视口的地块数量、棋盘外框和页面 `scrollWidth`。） **证据：C08**
- [x] 手机点按任一类型地块可阅读完整详情；城市详情仍显示原价格、归属和可用操作。（验证：分别点城市、机场、起点、机会、休闲、监狱、极地地块并观察弹窗。） **证据：C09**
- [x] 地图资产卡显示当前本人真实总资产、现金、城市、机场及持股，不使用 demo 示例值；可打开完整资产视图。（验证：对局状态变化前后比对卡片与资产总览数值，并点击完整资产入口。） **证据：C10**
