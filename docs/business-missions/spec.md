# 经营任务 Spec

2026-10-14。用户“现在做”授权，按文档自审规则推进，不推送。首版两项自愿阶段目标，普通/快速适用。

F1 本人正常待掷骰可承接一个任务，一圈最多承接一次；只统计承接后的真实行为，不新增强制阶段/倒计时。可放弃，无额外扣款，放弃不补当圈次数。已有任务或未使用权益时不能叠加承接。
F2 建设实践：有非抵押未满级城市者可接，承接后成功完成一次普通落点建设且现金不少于6000达标；远程建设不计。奖励一次建房抵扣，最高1000且最多标准费10%，受原30个百分点总优惠上限和远程实付150%底线限制，仅有实际减额时消费。
F3 航线探索：现金至少6500且存在机场可接；承接后成功支付正额机票飞到另一机场、操作后现金不少于6000达标。免费飞行/骰子机场/机会位移不计。奖励一次机票抵扣，最高1000且最多原机票20%，与原优惠共用总上限（新局60%）；零费用不消费。
F4 任务在承接后本人第2次起点结算结束时到期，权益在完成后第2次本人起点结算结束时失效。完成/放弃/到期/权益使用均服务端唯一记账；转手、重复请求、重连不复制奖励。权益无现金/资产估值，不抵押、不转让，出局/封盘清除。
F5 任务与已赚取的经营订单、主动经营次数独立；界面私有显示目标、条件、期限、状态与权益，细节可查看但不强弹。AI可自愿接可达任务，遵守相同规则，快速尾声不接难完成的任务。新局business-missions-v1，旧局不迁移。
N1 沿原整数/报价/提交/回放，不加依赖。N2 私人进度不泄露；三端可操作，缺资格解释。
AC1/F1 一圈一个/同时一个/自愿/取消与不补时。AC2/F2 普通建设6000边界、远程不计、1000/10%/30%/150%优惠。AC3/F3 正额飞行及现金边界、免费不计、1000/20%/60%上限。AC4/F4 两次真实GO、使用/重复/终局，无权益资产计值。AC5/F5 私有显示、AI/旧局/回放/三端和有限联机。
