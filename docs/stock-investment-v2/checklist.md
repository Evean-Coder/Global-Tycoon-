# 股票投资改进 Checklist

2026-10-15。共36项，本地有限验收已执行；具体证据、环境和未测边界见acceptance.md。本表验收正式实现；numeric-model.cjs的候选算术通过不代表本表通过。

## 版本、操作与报价

- [x] C01/AC1：新局经营只显示订单/施工，股票普通买卖不耗经营；旧局仍保持原三路线和旧股息。（固定新旧局＋UI观察）
- [x] C02/AC2：全城10、城主2、外部4在买入、受让及产权改变路径一致；超额请求不部分成交。（固定边界）
- [x] C03/AC2：掷骰前2股1城、起点4股3城各2的累计限制准确，卖出/重连/关闭不恢复额度。（engine＋socket）
- [x] C04/AC3：0–4级价格、90/100/110/115系数、抵押80%、整数及最低1准确。（人工例＋固定输入）
- [x] C05/AC3：上市不足3完整轮按100%，上市当轮不伪造完整样本，窗口只保留3轮正额租金事实。（时序场景）
- [x] C06/AC3：建设、拆房、抵押及恢复改变报价后，旧报价提交失败并显示新金额；不沿用旧平滑限制。（engine＋UI）

## 退出、来源和估值

- [x] C12/AC5：买价1200、现价1920的单份普通回收1080；现价960时回收864，前后准确解释亏损。（quote＋UI）
- [x] C13/AC5：不同取得成本、取得顺序及0成本份额部分出售FIFO一致，显示合计等于到账金额。（单位账本场景）
- [x] C14/AC5：自救、购地、机场、建房募资都可卖指定股数并更新缺口、继续原流程。（4种入口固定状态）
- [x] C15/AC5：超城主2股按90%同价减持；银行清算先取价再按50%和来源上限结算，注销不重复退款。（产权与清算场景）
- [x] C16/AC5/AC8：买股→建房→银行卖股→拆房，以及抵押/赎回/产权变化，不能抬高来源上限向银行套现。（有限对抗序列）
- [x] C17/AC6：高价、低价、0元及余数转让成本与银行上限分别准确；多次倒手不能提高旧份额上限。（固定序列）
- [x] C18/AC8：股票净资产用银行回收额，市场参考价另列；建设及玩家高价倒手不凭空提高总股票可变现价值。（资产和quick排名）

## 邀请安全及持续操作

- [x] C19/AC6：买入请求/卖出邀请可同意拒绝，单城1–4股、每人每回合一次及2%卖方手续费准确。（真实socket）
- [x] C20/AC6：被邀请份额出售后再买回，即使编号相同，也不能接受旧邀请。（取得序次场景）
- [x] C21/AC6：现金不足、配额/身份改变、报价变化或清算时不部分扣钱、扣股、写账本。（失败前后快照）
- [x] C22/AC7：最多20秒且不超过原决定/整局期限；过期回复、重复回复、取消/接受竞争只有一次终态。（假时钟＋socket）
- [x] C23/AC7：任一离线、出局、掷骰或离开原窗口立即终止，重连不能复活，全员暂停不延长旧邀请。（断线与阶段场景）
- [x] C24/AC7：接收人可拒绝，原玩家可继续掷骰/结束窗口，第三方原操作不被新全局阶段阻断。（三参与者socket）
- [x] C25/AC7：非当事人不能回复；本人正在自救/募资/拍卖/受保护付款时不会被邀约额外扣款。（权限矩阵）
