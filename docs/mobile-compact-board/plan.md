# 手机横屏完整棋盘 Plan

日期：2026-10-14。Spec/Plan/Tasks/Checklist已自审并获最终开发授权；本版按用户后续“保持原有布局”修正。

## 1. 架构与布局

手机识别复用MobileOrientation.isPhone的环境口径，横屏才启用compact-landscape；常规平板及电脑保留既有perimeter/landscape。沿用12列×11行，外圈格数2×12+2×11−4=42。DOM依然按id0–41存放；只改变Grid位置，游戏board、步数和顺序不改。

BoardLayout.position(id,mode)始终返回原坐标：0–11顶行，12–20右边，21右下角，22–31底边，32左下角，33–41左边；41→0相邻。所有模式精确映射一致，视觉拐角及行走路线不变。

BoardLayout.geometry(mode)提供rows/columns和anchors：topLeft0、topRight11、bottomRight21、bottomLeft32（全部模式相同）。placeBoardSurfaces读取几何锚点替代硬编码11/21，中央地图按真实内边界铺满；棋子仍由真实DOM地块位置计算。

## 2. 地块表示与产权

boardPresentation只读模块：tilePresentation(square,state)返回fullLabel、shortLabel、kindLabel、glyph、ownerId/ownerColor/ownerSeat及detailLabel。默认城市名仅用城市，无国家；卡萨布兰卡→卡萨、阿姆斯特丹→阿姆、墨西哥城→墨城、里约热内卢→里约，其余城市最长三字；机场用开罗/希思罗/肯尼迪/浦东并配飞机。特殊格用起点/机会/休闲/监狱/南极/北极。简称表对所有42格完整覆盖，详情与aria-label保留全名。

图标使用本地内联SVG/既有符号，地产房子、机场飞机，无网络字体和图片依赖。单行“编号＋短名＋图标”；价格/房级/抵押/姓名只在compact隐藏并从详情阅读，PC保持。产权用玩家真实color的边条和低饱和淡底，中性无主；原房产色组在手机详情标示。图例给席位、颜色和姓名；不靠全块深色传达持有者。多人同格若逐个棋子遮挡短名则聚合为人数/颜色标记，详情列出实际同格玩家；主移动和当前位置保持真实，非新游戏数据。

## 3. 顶栏、操作区和信息展开

单一状态顶栏预算44px：当前玩家/轮次、当前决定余时、快速整局余时，常态隐藏长标题与装饰副标题；长玩家名截短显示但可从玩家资料看全名。原timer/quickTimer DOM复用，不建第二个时钟。waitBanner与状态原因并入状态入口，仍需可读/可访问，不再额外占独立纵向条。

底部预算48px，按钮高至少44：骰子、经营、资产、银行、更多。前四顺序保留；股票恢复原按钮复用同一槽位，监狱/冻结/自救等原可用状态保留，不授予新权限。更多内提供股票市场、经营任务、当前/其他玩家、资讯、事件、定位、规则、认输/解散原入口。

compact保留棋盘左、信息右的原布局：主区3:1列宽，中央仍是左资讯/右台账两个同高面板，实际矩形保持地图宽86%、高72%且居中。只缩小字体/留白，面板和侧栏可独立滚动。更多打开时暂移原资讯/侧栏DOM放大阅读，关闭或其他决定接管时立即移回原父容器，不用摘要替代原资料。reuse DOM保持id唯一，不克隆按钮或重复绑事件。资料reader带kind并由服务端新快照刷新实际数据，captureReading/restoreReading保存展开/滚动；本人的新强制决定按原优先级接管，横屏门禁最高。PC恢复原父容器和样式，不能让移入抽屉的DOM永久丢失。

## 4. 尺寸预算与回退

以下仅几何预估，开发后必须以浏览器实际盒子验收，不能当作截图通过。扣除顶44、底48及上下留白8，共100px；棋盘占主区约75%宽，右栏约25%，格间隙1px。

固定外围42格、整板width/height100%，不设置旧560px最小宽度或44px最小格高。最窄视口短名字号8px，按视口增大至11px；预算必须包含边框和图标。中央背景铺满实际矩形并显示完整世界，读详情按钮不塞进小格。

ResizeObserver/visualViewport变化在animationFrame合并测量；先布局→更新中央边界→棋子定位，移除旧内联宽高/滚动偏移。系统安全区或更小可用尺寸导致棋盘可用高度低于177px或宽度低于405px时，提供明确“放大地图”查看模式，地图最小553×366、地块最小44×32，独立滚动，正常动作仍44px；默认支持尺寸不进入回退。放大只是视图状态，关闭回全图，不改对局或倒计时。系统缩放不强行锁死。

## 5. 数据流与关键决定

真实gameState→现有渲染器→只读短名/归属表示→手机布局/信息reader；点击squareId沿原openCityDetail/openSquareDetail，返回恢复焦点和全图。地块按squareId原地更新DOM，不在每次广播替换所有按钮，保留点击目标与焦点。产权转让/清算后从新ownerId重画；地图色条不复用旧缓存产权。城市详情保留抵押信息及经营数据，特殊格追加同格玩家列表。

客户端展示模式不增加服务端规则标识、Socket消息或游戏状态字段。只保存UI布局/打开信息kind；不持有第二份资产/行情/倒计时。动画仍220ms/格，终点以快照为准；聚合标记与单独移动棋子共用lastPos，不能遗漏排队状态。

PWA资源统一升版本，升级不强制刷新进行中的对局。有限布局/交互、身份/草稿、动画/缩放及PC回归；旧scroll检查按新需求改为全图不滚动，保留放大模式滚动验证。

## 6. 覆盖与自审

F1几何，F2表示，F3归属/图例，F4原详情，F5顶栏/底栏/抽屉，F6真实边界/棋子，F7原控制及PC恢复全部有归属。共用现有BoardLayout、MobileOrientation、渲染器、资料reader与缓存，不引入环依赖或副本状态。主要风险是短屏尺寸和不同父容器的焦点/读状态，作为验收门槛，不以隐藏资料消除失败。
