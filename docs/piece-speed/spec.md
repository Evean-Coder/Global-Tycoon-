# 棋子半速移动 Spec

## 目标与功能需求

- F1：玩家棋子在棋盘上的逐格移动速度降为当前一半，即同一路径耗时加倍，PC、平板和手机一致。
- F2：移动完成后仍落在服务端指定地块，后续状态按原顺序处理；减少动画设置继续直接显示最终位置。

## 约束与边界

只调整移动显示速度，不改变骰子、移动路线、服务端规则、决定期限和骰子动画速度。沿用既有技术栈，同步资源缓存，不刷新在玩对局。本轮不推送，不跑整局模拟。

## 验收标准

- AC1 / F1：普通动画每格耗时为原来两倍，有限实际状态移动可观察到逐格前进。
- AC2 / F2：动画期间收到下一状态仍正确衔接，最终地块和后续查看操作正确；减少动画时无逐格等待。
- AC3：缓存升级、lint及差异检查通过，仅本地保存。
