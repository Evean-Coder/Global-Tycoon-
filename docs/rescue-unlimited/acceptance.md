# 自救身份、原因与无限时验收

日期：2026-10-13。本轮仅本地保存，没有推送或部署。

## 完成内容

- 自救窗口顶部常显需要自救的玩家、付款原因、当前缺口；租金/机场等已知付款显示城市或机场、收款玩家和原付款金额。其他玩家在玩家面板看到自救身份、原因及缺口。旧资料缺失时不编造。
- 普通与快速模式self_rescue不建立超时任务，deadline及剩余秒数为null，保留稳定决定ID；部分筹资及重连不重置。自救计时区域显示“自救无时限”，暂停时显示无时限暂停。
- 移除服务端自救超时默认放弃。没有可变现资产也不会因等待破产；足额后按原引擎继续，主动点击“放弃自救并破产”才处理负现金破产。
- 出售/拍卖上下文保留原付款事实；独立买方/竞拍决定维持原期限，返回自救仍无限时。AI继续原自救策略。快速整局30分钟封盘按原净资产结算，不把等待自救当破产。
- 不改变资金、产权、费用、其他决定期限和正常重复请求处理。资源 `20261013-rescue-unlimited-v1`，缓存 `global-tycoon-v37-rescue-unlimited`。
