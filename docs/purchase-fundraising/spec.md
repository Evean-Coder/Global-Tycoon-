# 购买募资与自救出售 Spec

日期：2026-10-12。用户已统一批准未完成整改、要求先完整开发文档；按本次反馈自审实施。

## 目标及需求

- F1 购地、购买机场募资时显示当前持股，可选择整数股数出售；无持股或不可卖出说明原因。
- F2 按原当前股价变现，现金、持股、尚缺实时更新；资金足够不自动购买，须手动完成；取消保留已变现现金。
- F3 原服务端身份、报价、数量、重复请求与截止校验保持；失败不改余额，不增加决定时限，不允许普通银行随意卖股。
- F4 复验自救拆房、出售城市及拍卖；出售等待买方时明确显示等待者与成交规则，不能造成点击无反馈或重复成交。

## 范围及约束

不更改报价、税费、产权、上市、回合或倒计时规则，不新增事件、依赖。沿现有原生前端/Node20。三端可操作，缺口以真实状态为准。不跑批量完整对局。

## 验收

- AC1 两种购买目标、两模式的募资界面均有数量卖股和无持股说明（F1）。
- AC2 部分出售、足额、手动购买、取消后现金及产权符合原规则（F2）。
- AC3 非本人、非法数量、旧报价、重复、过期及封盘不多次变现，原截止不延长（F3）。
- AC4 自救拆房和出售可正常推进，买方成交/拒绝后恢复真实自救上下文；卖方等待可见（F4）。
- AC5 手机/平板/PC有限浏览器、服务端回归、lint及缓存同步通过（F1–F4）。
