# 有限预算平衡检验 Spec

2026-10-03。用户已批准提案并要求“开始吧”；沿用测试过程中自行审批、不再提问的授权，本执行规格自审通过。授权仅限测试工具与证据，生产玩法不改。

## 背景与目标

利用既有结果、受控局面和短分支，在有限成本内寻找可复现的收益循环、经营选择风险、机遇组合异常、现金压力与局部顺序问题。不将小样本当成总体胜率证明。

## 功能需求

- F1 保留原规则及旧证据，登记固定输入、案例、种子、独立输出与执行版本；受控人工局面标明性质。
- F2 只读已有摘要与策略，分清实际收益、本金、估值、现金注入和转移，不重复重放/重采样。
- F3 检查48核心案例（四类各12），每项机遇至少一例；最多24预登记边界例，记录预期与实际、费用/收益/额度和失败。
- F4 最多12组成对短分支，起始状态和随机流一致，只改首个决定；每条最多10完整轮或160成功动作。失败/预算中断标缺失，不按领先判胜。
- F5 累计程序执行最多20分钟，A/B/C/D分别4/8/5/3分钟，自动到期保存并停止；重启不清零，用额度核对与墙钟守卫覆盖编排开销。
- F6 核对现金循环、资产风险、机遇门槛、租金银行补足及轮次边界；同等身份映射核对资格和结算，正常起局争夺不纳入公平证明。
- F7 输出具体问题、风险、所检范围未发现风险、未验证四类结果；区分局部可复现错误与未证明因果，原胜率门槛不降。
- F8 必要工具回归与静态检查，按实际数量和缺口验收；默认0新增完整局。确需完整重现按提案最多6局且替代分支、共享C预算，不自动启用。

## 非功能需求

- N1 本地运行，不逐动作调用模型，不访问真人房间、不改变原随机语义与生产依赖。
- N2 有限证据，预算/锁/输出保护可验证；只写新目录，错误中断受影响实验。
- N3 相同控制输入可重现；个人决策只看本人视图，人工局面和正常轨迹证据分开。

## 不做的事

不继续旧大矩阵、不重新做50000次统计、不调整生产经济数值、不宣布真实胜率平衡、不编造真人试玩。没有充足覆盖的环节明确未验证。

## 验收标准

| 标准 | 对应需求 |
|---|---|
| AC1 原30文件指纹和旧预算摘要一致，版本/输入与独立目录齐全 | F1 |
| AC2 已有资料来源、四路线参数及金额口径可追溯，不新增完整对局进行资料整理 | F2 |
| AC3 48核心案例实际记录，每项机遇与固定组合覆盖，预期/实际及状态证据可核对；到期缺失明确列出 | F3、F6 |
| AC4 12组成对分支或实际完成/缺失列表，首动作以外同一决策规则，条数/轮数/动作上限严格 | F4 |
| AC5 阶段上限、累计额度与停止/恢复守卫实际验证，重启不清零 | F5 |
| AC6 四类结论依据明确，不把正净注入、低使用频率或较高资产当作全局失衡/胜利 | F6、F7 |
| AC7 必要回归和静态检查有实际日志；完整局启用数与真人执行状态如实报告 | F8 |
| AC8 登记→受控动作→分支→有限结果报告端到端，旧报告和统计结论未覆盖 | F1–F8 |
