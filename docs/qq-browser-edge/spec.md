# 手机横屏内容左移 Spec

日期：2026-10-18。用户明确纠正：所有手机浏览器横屏统一将内容左移，利用左侧空白。此指示替代此前QQ专用、8px上限及开关草案；按用户当前要求实施。目录名保留最初问题来源。

## 背景与证据

荣耀X50／QQ截图中顶栏、棋盘、底栏一起右移。现有整页padding直接应用浏览器左安全区。844×382模拟原左安全区40px后，顶栏位于40px、棋盘和底栏位于44px；0px对照分别为0px和4px，与截图形态一致。该证据仅为模拟，未直接读取用户真机的安全区。

## 功能需求

- F1 所有现有手机横屏对局使用完整左侧可用内容区域，取消整页额外左安全区留白；顶栏从页面左侧开始，棋盘／底栏仅保留原4px正常内边距。释放的宽度用于内容重排，右边缘不因整体平移而留下新空白。
- F2 保留原顶部、右侧、底部系统边距及横屏门禁；桌面和平板原布局不变。不按浏览器品牌、操作系统或手机型号建立特殊分支。
- F3 保持12列×11行、42格及原中央资讯／台账和右侧玩家栏相对布局；地图与棋子按新宽度对齐，主要按钮仍至少44px高，极小空间沿用地图放大回退。
- F4 旋转、浏览器可用尺寸变化及广播后保留真实落点、阅读状态、股票草稿和期限；只修改布局，不发送额外游戏动作。
- F5 同步前端资源缓存，升级不强制刷新进行中的游戏；真机／模拟／线上核对分开记录。

## 范围与约束

复用现有手机识别和compact布局，不新增依赖、控件、设置、服务端事件或规则。本轮不重做棋盘或字号，不用负margin或transform把固定宽度内容挪出屏幕。真机摄像头附近的实际可用性需由用户复看，不将模拟写成硬件验收。

## 验收标准

- AC1/F1：手机横屏模拟左安全区0／8／40／80px时，整页左padding均0，顶栏left=0，棋盘和底栏left约4px；右边缘保持、无横向溢出。
- AC2/F2：顶部12／右24／底20px继续生效；QQ、普通Android、iOS代表UA均执行同一布局；PC／平板与竖屏门禁保持原行为。
- AC3/F3：两模式568×280、844×382、932×430显示完整42格，中央图片铺满、棋子对齐、操作按钮高度至少44px；释放宽度实际增加棋盘可用宽度。
- AC4/F4：股票草稿、展开阅读、快照资金和决定期限在布局变化／广播前后保持。
- AC5/F5：缓存升级、必要回归及静态门禁通过；推送与Render核实后报告真实结果，荣耀X50真机复看另列。
