# 移动端可玩性与布局重整 Spec

日期：2026-10-11。状态：2026-10-11用户统一批准开发；实现与实际验证见 acceptance.md。

## 背景与目标

用户三张实际手机截图显示：竖屏顶部和底部空间过大，棋盘与长台账难浏览；横屏有效棋盘区域狭窄，无法顺畅操作。对局记录及代码核对见reproduction-notes.md。目标是重新安排手机信息和动作层级，让普通/快速、真人/人机都可用，保留统一Atlas风格。

本次拟修订此前手机6×17周边棋盘设计：手机改用6×7紧凑蛇形线路，每格仍按0–41原顺序行走。此为展示方案变更，须开发确认；服务端格序、落点、骰子、费用和规则不变。PC/正常平板继续现有周边棋盘。

## 功能需求

- F1 手机默认竖屏可玩，不强制旋转；自行横屏后也有完整可用的布局。大厅、房间、对局和弹窗均不出现整页横向溢出。
- F2 对局顶部缩为紧凑身份/规则入口及一行时间状态；个人决定时间与整局剩余时间明确区分。封盘说明进入可查阅帮助，不反复占据大横幅，断线等关键状态仍可见。
- F3 手机棋盘采用6×7蛇形线路，42格唯一、顺序明确，有编号和转向提示。地块名称、价格、归属、房级和抵押文字继续显示，支持点按原详情；棋子对应真实格，不与其他信息重叠。长名称换行，不用隐藏/省略代替信息。
- F4 世界地图作为独立、适当比例的地图视图或低对比底纹，完整大陆不裁切、不拉伸；取消棋盘中央的长台账。个人现金、总/净资产摘要在独立区域显示，完整资产沿原入口查看；不混淆可支付现金与排名估值。
- F5 玩家、机遇、资讯和事件信息通过独立信息区有明确可见入口；切换仅查看，不丢数据或发送游戏动作。手机无需滚过17行棋盘才发现这些信息。当前玩家、本人位置和当前决定原因易找到。
- F6 底部保留当前主要动作及少量查看入口，明显缩减占高；隐藏当前不可执行的重复主按钮时保留解释，不改变动作含义。主动经营入口保留，机会强调若组合批准则按其独立规格接入；不把资产、银行、结束回合等四个大按钮永久铺满多行。
- F7 横屏低高度视口采用棋盘与信息/操作左右分区；棋盘拥有可实际滑动查看的区域，动作不横盖棋盘。缩放、旋转、浏览器工具栏展开和键盘弹出后，仍可找到当前控件与返回入口。
- F8 普通/快速、真人/人机、2–4人及长昵称/多房屋/抵押/较多事件均采用同一布局规则。重连、动画、超时、封盘和旧局继续沿原状态处理，查看与旋转不续期或提交动作。

## 非功能需求

- N1 沿用现有原生前端、素材、Socket协议及服务端规则，不增加框架或运行时依赖；不读取隐藏随机信息。
- N2 320–430px手机宽度、至少280px高的横屏测试视口及正常平板/PC通过；文字正文通常12–14px，地块至少11px，主要触控目标至少44×44px，支持键盘、系统缩放和减少动画。
- N3 留白、边框、字体和主题色统一，减少重纹理与大阴影的叠加；不依靠不断动画或闪烁区分状态。有限视口允许棋盘内滚动，不承诺42格完整文字与所有面板永远同屏。
- N4 固定真实状态与有限浏览器验证，保存可见性/遮挡/高度数据与截图；旧“DOM存在即通过”检查不能代替实际可操作。不跑大量完整对局。

## 本轮不做

不改任何经济/胜负/库存/回合次数、不扩展移动端横屏规则、不强制安装PWA、不裁掉地块或玩家信息、不更换为另一种游戏美术主题。股票时限、滚动稳定、建房卖股及主动经营提示分别有独立规格；若组合交付共用最终资源版本，分别验收。
