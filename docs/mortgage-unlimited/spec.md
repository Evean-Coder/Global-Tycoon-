# 取消抵押数量上限 Spec

日期2026-10-12。用户明确要求取消上限并推送Render；沿用完整文档先行、自审授权。

## 背景与目标

当前真人、电脑及筹资入口都限制同时抵押2座，统一取消数量限制。

## 功能需求

- F1 普通、快速模式允许抵押任意数量的自有未抵押城市，正常抵押、自救、购地/机场及建房筹资一致。
- F2 银行、资产、地块详情、筹资和规则显示已抵押座数及无数量限制，按钮不因已抵押2座而禁用。
- F3 电脑评估和异常回退考虑所有合法抵押城市，继续按收益损失选择；不强迫抵押。
- F4 验证后提交并推送部署分支，核对远端与Render实际版本；记录成功、失败或未能核实。

## 约束与边界

本金仍标准价值50%，原利息、不能重复抵押同城、产权/阶段校验、赎回和倒计时保持。适用当前代码支持的两种规则版本，不新增状态或框架。历史策略基线、历史文档不追改。不做长期胜率模拟。

## 验收

- AC1 两模式及旧规则正常抵押第三座以上成功，一城只到账一次；他人城市及禁止阶段无变更（F1）。
- AC2 自救、三种购买/建设筹资第三城可抵押，原现金/缺口及手动确认语义保留（F1）。
- AC3 三端银行/资产/详情/筹资按钮可用、文案无两座限制，实际点击第三城成功且截止不延长（F2）。
- AC4 AI在已有两座抵押时能生成第三城抵押候选，原收益比较与自救回退仍合法（F3）。
- AC5 有限回归/lint、PWA升级通过，GitHub远端与部署证据明确（F4）。
