# 本轮开发与验收

日期：2026-10-14。用户“现在做”及“继续未完成的开发”授权实施；文档按既有授权自审。**仅本地保存及提交，不推送。**

## 已完成

- 新局启用disconnect-v1：非必要玩家离线不挡在线者，普通必要决定最多等20秒且不延长原期限；持续失联保守托管，重连不能反复获得等待预算；同步机遇只替离线未提交者选当前最左项。
- 自救仍无独立时限，离线自救等待本人重连；全真人离线暂停个人决定和AI。快速整局30分钟继续，到时封盘。
- business-missions-v1：每圈自愿接受一次建设/航线任务，同时一个任务；完成后获得一次有限建房/机票券，任务及券分别两圈有效，原费用总优惠上限不变，不计未赚取资产，不占主动经营次数。
- world-news-v2：地区租金±30%/6000，建设25%/3000，机票40%且合计最多60%；订单扶持只奖励实际到账的订单款10%/最高150。原三轮持续/预告/袋/股价公式保留。
- 真实报价、本人私有快照、唯一结算/回放、AI可达/储备/尾盘判断、只读帮助、阅读状态与本地缓存接入；旧局按原版本。
- 资产任务摘要移到操作区上方，关闭按钮恢复在末尾。手机触控检查改用真实touchStart/move/end，并核对地图滚动后按钮可操作；旧回归显式固定历史离线版本，新增测试核对新模型。
- npm test只发现test目录，浏览器测试由test:e2e单独运行，修复CI在安装浏览器之前重复发现e2e的问题。证据目录可单独配置以避免历史文件占用。
