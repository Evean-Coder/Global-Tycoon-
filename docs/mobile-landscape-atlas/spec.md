# 手机横屏 Atlas Spec

日期：2026-10-12。依据用户参考截图及统一开发授权，文档自审后实施。

## 目标与需求

- F1 横屏采用参考图结构：左侧12列×11行42格环形棋盘，矩形中央完整世界地图与单一纸色资产浮层；右侧本人、其他玩家和事件；底部全宽操作栏。
- F2 地块名称、价格、房级、抵押及归属文字保留，长内容换行；不通过无限缩小或隐藏信息换取一屏。低高度/窄横屏允许棋盘内部双向滚动，整页不横向溢出。
- F3 资产模块位于棋盘内侧，不遮挡外围地块；真实现金、估值、完整资产、机遇和资讯入口保留；地图完整显示、不拉伸，素材沿用。
- F4 右侧卡片单独滚动，玩家和事件均有可见标题；底栏固定独立布局，主动作、资产、银行、结束回合及个人时钟清楚可触达。主动经营仍从资产模块进入。快速整局时间另列。
- F5 竖屏继续6×7布局；PC、正常平板及大厅/房间保持原布局。旋转、浏览器高度变化及缩放只改变显示，不修改操作、草稿、倒计时、服务端格序或状态。

## 约束与范围

延续现有纸色Atlas、原生前端、Socket与素材，不增加依赖或游戏规则。主按钮至少44px高，地块至少44px宽/高，文字可换行。极低高度不承诺42格和所有信息一屏全部可见。有限受控状态、触控和截图验证，不跑大量对局。

## 验收

- AC1 844×390、932×430、568×320和844×280均为左环形棋盘/右玩家事件/底操作，42格唯一且位置顺序与服务器相同（F1/F2）。
- AC2 棋盘内部可滚动至首末、四角地块，点按详情可用；地块文字不隐藏，长昵称、房4和抵押仍可查看（F2）。
- AC3 地图与资产浮层完全位于内矩形，中央完整地图、现金与资产入口可见，不覆盖外围地块（F3）。
- AC4 底部按钮/个人时钟位于视口内、不叠盖棋盘，银行可直接打开；右侧玩家/事件实际可滚动阅读（F4）。
- AC5 竖→横→竖不变状态或截止，股票草稿保留，棋子与真实地块定位正确；PC/平板、原募资/赎回及缓存回归通过（F5）。
