# 三路线 v4 验收

2026-10-14。用户明确批准开始开发，T1–T14已实施。仅本地保存，未推送GitHub或部署Render。

## 实现结果

- 远程建设：目标房级150%/200%/300%/350%，优惠合计最多标准费30个百分点、实际最低150%；零减额不消耗优惠。成功后再经过本人起点3次，且不能连续成功建设同一城；普通落点建设费用保持，历史与冷却不随换机遇、买卖城市或正常建房重置。
- 经营订单替代促销：自有非抵押城市或自有机场，预付基础价10%最高1000；后续两次本人回合开始各收12%最高1500。每个人圈一单、同时一单，同一turnId不重复支付；监狱/冻结回合照常结款。产权、抵押、出局或封盘取消未领款，不退预付，未赚收入不计资产。
- 主动买股：一次1–4股免手续费，无新增圈买股限额，保留20股/城主4股。正常起点实收基础现金股息另奖30%、购买圈最高1500；仅标记且仍持有的份额有效。本人起点内先结本次自有城派息，再结束旧资格；卖股/转让/强制减持优先扣标记，清算/换挂牌清除，受让不继承，转让派息及封盘不奖，与H4不复利。
- UI、AI、私有快照、通用记录/回放、规则目录及缓存同步。新局使用active-management-v4；v1/v2/v3不迁移。AI按实际报价比较路线，快速尾声不足一个估计本人回合时不新增经营投入。
