# 回合经营弹窗与主动放弃 Spec

2026-10-13。用户要求回合开始以高优先级弹窗呈现主动经营，允许不经营，主界面底部左「放弃经营」、右「关闭查看」。本修订替代经营v2中必须投资及超时最低支出规则；沿用文档自审授权，当前发布暂停，仅本地交付。

## 功能需求
- F1：本人每个正常待掷骰回合自动展示一次经营类型主界面，即使没有可执行城市也显示原因。其他玩家不弹。初始/后续强化、监狱、冻结、自救、拍卖等决定优先完成，回到正常待掷骰再弹。旋转或同回合广播不反复弹出；重连/刷新在尚未处理时恢复提示。
- F2：经营为可放弃的选择。有项目时掷骰前执行一项或明确放弃；无项目可直接掷骰。放弃仅结束本回合经营机会，不扣钱、不改变本圈投资/促销额度，不结束回合或自动掷骰；放弃后本回合不能再经营。
- F3：关闭查看只收起弹窗，保留未执行决定和有效草稿，底栏可再打开。有项目且未执行/放弃时，关闭查看不解锁掷骰或等效结束。两种按钮含义常显，不采用关闭即放弃。
- F4：主界面底部固定并排，左放弃经营、右关闭查看；不随长城市列表滚动消失。子界面底部左返回选择、右关闭查看。经营弹窗高于普通资产/银行等查看窗口，横屏提示始终最高；主动打开规则说明时允许规则覆盖经营后返回。
- F5：经营成功或放弃后关闭弹窗并显示已经营/已放弃。失败保持决定、更新真实状态，迟到回执不关闭其他窗口，重复请求不重复记录。新的个人回合恢复机会。
- F6：超时未处理时默认放弃，再按原超时自动掷骰；不替玩家投资。普通90秒、快速45秒共享期限，查看/返回/放弃不续时，封盘优先。AI按收益选择经营，收益不合适可放弃。
- F7：新局采用经营v3；v1/v2旧局保持既有规则和超时策略；三类经营数值和12项强化沿用v2，目录/缓存/规则同步。

## 约束与范围
沿用现有前端和动作请求去重协议，不新增倒计时，不改变价格/分红/建设/促销效果。最高优先级手机横屏阻挡继续生效。有限指定测试，不运行大量整局。

## 验收
- AC1/F1：仅本人正常回合自动一次，暂停/强化/强制阶段不被覆盖；同回合关闭、旋转及广播不复弹，下回合和重连恢复。
- AC2/F2–F3：放弃无金钱/产权变化，解锁掷骰且不能再经营；关闭无服务端变化、保留草稿，仍可重新进入，有项目不能绕过。
- AC3/F4：PC/平板/手机横屏主界面底部按钮顺序正确且可触达，子界面返回可用；经营高于普通弹窗、横屏提示高于经营、规则帮助可返回。
- AC4/F5：成功、失败、重复及迟到回执、下一回合恢复各验证；私人状态仅本人获得。
- AC5/F6–F7：v3超时放弃并掷骰一次，不花钱；旧v2行为不变；AI合法放弃；缓存、目录、必要回归和lint通过，交付只在本地。
