# 有限预算平衡检验 Plan

2026-10-03。在自审通过spec基础上，按测试自审授权批准本设计；不涉及生产规则修改。

## 架构与接口

1. 控制器：独立run目录、输入哈希、PID锁和持久预算；A/B/C/D串行执行。以performance单调墙钟计活动时间，每条案例/动作前检查，阶段结束计入编排与落盘开销。超时写暂停证据，不挤占D。每次操作粒度有限，不承诺能抢占正在执行的单个同步动作。
2. 案例模块：createFixture、own、grant建立明确人工状态；caseCatalog返回48个{id,category,name,run}。真实economy/stocks/logic结算与normalizeAction资格校验，断言从公开规则手工定义的预期数字/条件，不能仅用同一公式生成期望。额度/基金/所有权由assertEconomy检查。
3. 分支模块：branchCatalog固定12对、3现金/风险条件×4主题。createSession source=controlled，真实视图/时钟/预检/复制提交；首决定外统一冻结neutral策略。人工中期局面不称正常轨迹，stage ordinal与取得机遇数量相符；rng起点相同而后续消费可能分歧，记录调用数。
4. 报告：只读旧A/C摘要与PROFILES/SCORES。金额按现金/基金/估值/股息/本金拆分；结果包含案例、断言、短流水、初末状态摘要、成功动作数、轮次变化、预算、版本与缺口。不做重新统计或总体胜率排行榜。

## 48案例登记（分类每类12）

- 股票：同窗买卖本金守恒；窗买入总额限制；城主持股限制；除息总值；重复派息；产权变更先派息；银行清算一次；低收益经营报价下限；高收益上限；每轮报价幂等；有价转让资金守恒；无价转让不生钱。
- 经营与顺序：低价建设回本；高价满级增量；优惠拆建损失；抵押自救/赎回代价；机场通行收入；普通航班费用；免费航班不耗优惠；两人租金身份映射；三人租金身份映射；四人租金身份映射；身份映射建设资格；完整轮边界requiredIds无固定首座。
- 单机遇：H1–H12逐项，真实合法生效与额度/条件，不将权限折成现金。
- 资讯/组合：旺季、淡季、建设优惠、航空促销、平稳各一；施工+H2+H3；H1+施工折扣；H6+H11；航空+H7；H4+除息；H5+H10；H9抵押边界。

本次默认0补例、0完整局。失败可限定登记最多24补例；不依胜者扩大。12短对照为建设/现金、股票/现金、航空/停留、H5投资投入/保留现金各3个条件。最后主题用于检查奖励的启动成本和流动性风险，不人为删去机遇。所有动作要通过真实资格校验；缺资格则记录工具/局面问题。

## 技术决策

- 新脚本放scripts/light-balance/，不进入原30文件指纹；复用既有session、canonical、policy及经济不变量。
- 不改production或原balance工具。只用Node20与现有包。
- 工具验证用很短的内存夹具和注入时钟：验证守卫/恢复、数量限制、成对初态与非勝率结论。受控48本身就是主要行为验证，不写镜像公式测试。
- 总额度与阶段额度落盘；已完成目录拒绝重跑覆盖，恢复只做未完成项，不重复已完成案例。输出体积限10MiB，超出安全停止。
- 报告用实际数据填值；若发现局面或工具缺陷，保留原失败、修正摘要及计费，限定重验，不能把失败重写为成功。

自检：所有F有模块归属，层间单向依赖；额度未降低、0完整局默认保持；个人策略复用本人视图，不派生服务房间。
