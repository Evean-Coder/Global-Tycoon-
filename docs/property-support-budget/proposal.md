# 置业扶持预算方案草案

日期：2026-10-13。状态：用户提出累计现金限制，正在讨论；本文建议值尚未确定，未修改实现，仍禁止推送。

## 用户方向

置业扶持作为默认隐藏机制，生效时仅向符合条件的玩家弹窗。购买范围排除纽约、上海；其他所有城市均有归属后，才开放仍未被购买的纽约和上海。用户随后暂停原单城方案，要求用现金支出限制允许购买一座高价值城市或几座低价值城市。

## 推荐方案

- 保留从未拥有城市、购地解锁后连续六个有效回合无可负担机会的资格条件。
- 将整局一次使用改为一次选购：在弹窗中选择一座或多座可售城市，最后统一确认购买。
- 本次选购总价上限建议为 ¥20,000，实际还受本人现金与本圈剩余购地座数限制。预算不会发放现金、减免地价或影响普通购地。
- 每座城市按原价支付，仍分别占用每圈四城额度；全部选择一起校验、一起提交，避免第一座取得产权后资格失效而导致后续选择无法完成。
- 取消或未成交不消耗机会；成功确认后即结束本次扶持，剩余预算不结转，下次不能再次申请。
- 候选变化、资金变化或额度变化时先刷新并让玩家重新确认，不能自动换城市；失败不得部分扣钱或取得部分产权。
- 纽约/上海是否开放由所有其他城市当前归属决定，不能因其他城市价格超过剩余预算、现金不足、处于出售中就提前开放。
- 历史规则按版本保留，新规则在新局默认启用；不回算旧局历史资格。
