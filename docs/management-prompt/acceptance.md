# 回合经营弹窗与主动放弃验收

2026-10-13。按用户要求及文档自审授权完成 Spec → Plan → Tasks → Checklist 后实施。新局经营 v3；v1/v2旧局保持既有行为。本轮未推送 GitHub、未部署 Render。

## 交付行为

- 本人正常回合自动显示独立高优先级经营弹窗，同回合主动关闭后不因广播或旋转反复弹出。
- 主界面固定底部左「放弃经营」、右「关闭查看」；子窗口左返回选择、右关闭查看。
- 放弃只结束本回合经营机会，资金、产权和本圈额度不变，不自动掷骰。关闭仅收起，保留类型、城市及股数草稿，有项目时仍须经营或放弃后掷骰。
- 超时未处理默认放弃后自动掷骰，不替玩家支出；AI在无合理投资时可放弃。经营数值及12项强化沿用v2。
- 手机旋转提示优先于经营，经营规则帮助可覆盖后返回。资源 `20261013-management-prompt-v1`，缓存 `global-tycoon-v29-management-prompt`。
