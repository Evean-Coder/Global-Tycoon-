# 环球大亨三端前端改版 Spec

## 背景

现有游戏具备大厅、房间、42 格对局棋盘、资产信息、操作栏和多类弹窗。当前窄屏棋盘信息过密，手机依赖棋盘内部横向滑动，平板缺少独立的信息布局，视觉层级和触控体验也不统一。用户已审阅离线视觉 demo，并确认以日光照射下的深海蓝水面、暖白卡片和少量金色为视觉基准；正式对局的棋盘中央应呈现有真实水面质感的世界地图，个人资产信息位于地图上层，外围地块比现版更大。

## 目标

- 统一大厅、房间、对局和弹窗的视觉语言，提高对局信息的辨识度。
- 分别优化 PC、平板横竖屏和手机的布局与操作，手机保留完整棋盘总览，并能点按地块查看详情。
- 保留现有游戏规则、联机状态和操作含义，让视觉改版直接服务于当前游戏。

## 功能需求

- **F1 统一视觉：** 大厅、房间、对局和弹窗使用已确认的深海蓝水面、暖白卡片与少量金色。对局中央显示有真实水面质感和世界地形层次的地图背景；棋盘地块呈现清晰的桌游材质与归属颜色。视觉资源必须在正式页面中可靠显示。
- **F2 PC 对局布局：** PC 页面同屏清楚呈现放大的 42 格棋盘、地图上层的本人资产概览、其他玩家和事件信息。资产概览可进入完整资产视图，常驻操作栏不遮挡地块和关键内容。
- **F3 平板布局：** 平板横屏和竖屏按可用宽度重排棋盘、信息卡和操作区，保留完整对局信息与可操作入口。
- **F4 手机布局：** 320–430px 手机宽度显示完整的 42 格棋盘总览，不要求在棋盘内部横向滑动；点按任一地块可查看完整详情。个人资产、其他玩家和事件信息可以方便地展开或滚动查看。
- **F5 状态与反馈：** 常用操作、倒计时、掉线提示、当前回合、错误反馈以及各类弹窗在 PC、平板、手机端清楚可见且可触达；布局变化不改变原有操作结果。
- **F6 全流程适配：** 大厅创建和加入房间、房间等待、对局动作、股票市场、银行、规则速查、结算以及现有恢复流程均适配三端。

## 非功能需求

- **N1 规则与协议：** 保留服务端规则、单骰玩法、42 格顺序、Socket 事件及现有操作含义；概念图中的双骰和示例数据不进入正式产品。
- **N2 技术约束：** 沿用现有原生 HTML、CSS、JavaScript 与 Node 20 部署，不增加前端框架或运行时依赖。
- **N3 可用性：** 三端关键文字和按钮保持可读、可点按；支持键盘焦点和系统缩放；启用减少动画设置时仍可完成操作。视觉资源加载失败时，文字与操作仍可辨认。
- **N4 布局稳定性：** 常见 PC、平板横竖屏和 320–430px 手机宽度不出现整页横向溢出，交互不因布局变化而失效。

## 不做的事

- 不调整游戏规则、地块顺序、单骰玩法、价格计算和服务端权威状态。
- 不改变 Socket 事件、按钮含义、弹窗操作顺序和联机流程，不新增游戏动作。
- 不引入前端框架、运行时依赖或独立的原生移动应用。
- 不把离线 demo 的示例金额、人物或展示性操作结果带入正式对局。

## 验收标准

- **AC1（F1）：** 大厅、房间、对局和弹窗采用已确认的深海蓝、暖白与少量金色；正式对局中央能显示世界地图与水面纹理，地块颜色可辨。视觉资源缺失时，文字和按钮仍可用。
- **AC2（F2）：** 在常见 PC 视口中，42 格棋盘及地块文字完整可见且比现版更大；本人资产卡叠放于地图内部、不遮挡外围地块，其他玩家与事件信息可见；操作栏不压住地块或关键内容。
- **AC3（F3）：** 在平板横屏和竖屏视口中，棋盘、信息卡、操作区按宽度重排，所有入口可见或可通过正常滚动到达，且互不重叠。
- **AC4（F4）：** 在 320px、375px 和 430px 宽度下，42 格棋盘在一屏宽内完整呈现，无棋盘内部横向滑动或整页横向溢出；点按地块后可读到其完整详情。
- **AC5（F2、F4）：** 地图上的本人资产概览显示当前对局的真实资产状态，并能打开完整资产视图；手机端可查看其他玩家和事件信息。
- **AC6（F5）：** PC、平板、手机的倒计时、当前回合、掉线、错误与弹窗状态清楚可见；键盘焦点、系统缩放和减少动画设置下仍能完成关键操作。
- **AC7（F6）：** 三端均可走通创建或加入房间、开始对局、打开资产、股票、银行和规则、处理现有操作弹窗并查看结算的用户流程。
- **AC8（F5、F6、N1）：** 改版前后的单骰规则、42 格顺序、服务端状态和 Socket 操作语义保持一致；视觉展示不提交新的游戏动作或更改已有操作结果。
