# 商业竞争草案自审

> 当前正式文档及自审改见[进度](progress.md)和[四文档自审](formal-review.md)。本页审查的是旧25%/3000/三次候选，相关模型不能作为新候选的证据。

2026-10-16。仅讨论，未批准开发，保持发布暂停。

## 设计决定

- 选择公开地区、隐蔽金额的单次竞价，统一完整轮结束开标；不按提交先后抢占，也不加全局等待。
- 发布时固定地区开放条件，随后按各份报名的真实标的校验，防止某人靠抵押自己的另一座城取消全场。
- 每人每期一次、一个地区、一座旗舰，限制多城玩家的规模放大。
- 原拟500最低价过高，调整为100–4000、步长100，低价城市可低额试探；不宣称每座城市都值得报名。
- 选定“25%、每次3000、两个完整轮、三次”作为待验证参数，收益必须有真实租金事件。
- 先资讯、再附加、再原个人减免；所有股息保持原口径并原子处理，不人为增记一次租金或报价系数。
- 现金不冻结，开标时资金不足会失效并顺延；界面必须在提交前讲清楚。落选只不扣现金，本回合经营机会已花掉。
- 上期地区赢家下一期不能报名该地区，不因提前抵押、出售或优势失效解锁；有效期内不开放插队夺标。
- 产权变动、抵押、出局立即终止优势；建拆房只影响下次实际租金，不补次数；快速封盘不折现竞争权。
- 不能宣称开标后所有人都有自由移动的反制；真正的直接竞争发生在报名轮。生效时的对手选择受现有合法行动限制。

## 仍存在的取舍

1. 高房级的附加高于低房级，本机制会放大一部分建设价值。一城上限、3000封顶和不能连任只能控制，不能据此断言已解决强者优势。
2. 两人模式短期到访较少，三次是上限而非预期；低价城市可能多数时候订单更合适。需以有限位置场景比较实际可达和净收益，不能以三次全触发做报价推荐。
3. 暗价且资金不冻结，允许报价到开标时失效。消耗经营机会有成本，但仍需检查AI和玩家是否频繁策略性放弃资金准备；不能靠未验证的新罚款临时解决。
4. 股东也分享附加租金，原银行40%追加因此可能增加支出；没有新造银行竞价奖金，但不能宣称该机制完全不增加银行支出。
5. 本机制的互动来自争夺公共资格、选址和出价；生效后仍是临时租金效果。若用户希望更强的生效中攻防，应该另行讨论核心玩法，不能默默增加袭击、抢城或强制交易。
6. 订单竞标若后续实施，会与此处的暗价流程有相似性，必须复审两路线的操作重复度。
