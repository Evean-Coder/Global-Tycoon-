## 使用方式

- 每项描述可观察的系统行为，验证方式和通过标准分列。执行时按编号记录实际输入、操作、输出、消息或截图及结论；通过后才勾选，失败先修复并重跑。
- 数值、轮次与计时可使用固定测试输入及可控随机/时钟，须注明验证层级；它们不能替代真实多人消息与浏览器操作证据。
- 完整端到端场景从真实创建/加入开始，通过合法动作推进，不通过修改运行中金额、股份或轮次伪造经过。界面布局夹具可用于长内容与极端视口，须与完整流程证据区分。
- 金额例子采用规格输入，单位均为整数游戏金额；功能检查符合规格，不等于路线平衡或胜率已经验证。
- 七类视口、键盘、真实200%缩放与减少动画分别记录；实体设备未测时明确未测，不将模拟视口或缩小窗口称为实体三端/真实浏览器缩放通过。
- 当前本机是 Node 24；要求的 Node 20 结果必须来自实际 Node 20 运行时。无法取得必需证据时保留未通过，不以预计可用代替。
- 最终验收记录以编号关联命令、场景、输入、预期、观察、版本、视口/设备、证据位置和状态。四份文档已批准并执行开发；实际结果见 acceptance.md。

## 统一玩法、兼容与基础流程

- [x] **V1 新建和重开统一玩法**（AC1、AC6）

  **验证：** 以二至四人分别创建房间开始，再在结算后重新开局；查看大厅、房间和对局。

  **通过标准：** 每次都先出现经营机遇选择；没有模式选择、启用开关或局中切换。

- [x] **V2 全入口使用自然名称**（AC1、AC19、AC20）

  **验证：** 查看大厅、棋盘、选择、能力、错误、规则、日志、结算和记录的固定及自动说明；用普通测试昵称排除用户输入干扰。

  **通过标准：** 入口使用环球资讯、经营机遇、已选机遇及批准按钮名称；产品说明无规格禁止的机制标签；不审查玩家昵称。

- [x] **V3 基础规则与原操作**（AC20）

  **验证：** 复走创建/加入、购置及募资、普通建拆、抵押赎回、银行、转让、出售拍卖、自救、监狱冰冻、破产认输和解散；对照原验证基线。

  **通过标准：** 42格顺序、单骰1–10及原骰袋规则、起始资金、GO基础奖励、首圈限制与胜负保持；仅出现明确批准的新规则差异。

- [x] **V4 旧对局和记录兼容**（AC19、AC22）

  **验证：** 用升级前已存在且缺新增信息的状态继续并重连，打开旧记录；再开始一个新对局。

  **通过标准：** 旧数据按原信息工作，不凭空生成机遇/分红/历史；新开局全部采用新规则，界面不提供旧玩法入口。

- [x] **V5 真实Node20部署及依赖**（AC22）

  **验证：** 记录实际Node20运行时的绝对路径和版本，在独立测试服务执行启动、健康检查、开局选择及关键规则；核对运行依赖和外部请求。

  **通过标准：** 取得真实Node20通过证据，无新前端框架/运行时依赖/金融账户或行情服务；Node24通过不替代本项。

## 完整轮次与安全边界

- [x] **V6 二至四人完整轮次**（AC2）

  **验证：** 分别构造二、三、四人一轮，完成每名应行动者；在股票、购买和募资子阶段重复操作。

  **通过标准：** 每个实际回合结束只计完成一次，全体应行动者完成才推进；子阶段不额外算回合。

- [x] **V7 连续跳过回合**（AC2）

  **验证：** 覆盖短期监狱多人连续跳过、冻结放弃、出狱失败及按原规则到期完成的回合。

  **通过标准：** 跳过逐人计完成，不漏轮或重复；需要选择的安全边界不会被跳过循环越过。

- [x] **V8 首位和未行动玩家出局**（AC2）

  **验证：** 分别让座位首位、尚未行动者和已完成者出局，继续同一轮。

  **通过标准：** 未行动出局不阻挡轮结束；已完成记录保留；首位出局后仍正常推进。

- [x] **V9 原利息与晚期监狱语义**（AC2、AC20）

  **验证：** 对照原轮数与原收费触发路径运行抵押计息、晚期监狱场景，包括选择暂停和连续跳过。

  **通过标准：** 新增完整轮次不改原计息/收费时点和金额；暂停续接不重复收费。

- [x] **V10 清算和子阶段安全边界**（AC2、AC3、AC20）

  **验证：** 在轮末购买、股票、转让、募资、自救和多城拍卖清算未结束时达到潜在边界，再完成其原续接。

  **通过标准：** 未完成期间不切资讯或插入新选择；清算完成后再处理边界；只剩一人优先终局。

## 五类资讯与公开时点

- [x] **V11 首圈解锁后启动**（AC3）

  **验证：** 分别在轮中和轮末最后玩家解除原首圈购置限制，继续合法操作直到安全边界。

  **通过标准：** 未解锁显示条件，解锁后的首个完整轮次边界启动，轮末解锁可在紧随边界启动。

- [x] **V12 三轮持续及剩一轮预告**（AC3、AC6）

  **验证：** 从启动观察连续六个已运行完整轮次，并暂停其中一个轮中子阶段。

  **通过标准：** 每项按3、2、1轮显示；完成两轮才公开下一项，第三轮结束切换；暂停不扣轮，刚启动不视为已运行一轮。

- [x] **V13 五类袋和跨组限制**（AC4）

  **验证：** 固定多个随机输入观察连续两组五类资讯及组间交接。

  **通过标准：** 每组五类各一次，跨组相邻类型不同；没有额外类型或无限抽取等待。

- [x] **V14 旺淡季独立地区轮换**（AC4）

  **验证：** 连续记录旺季五次及淡季五次的实际地区；验证同色罗马与悉尼。

  **通过标准：** 两类各自五次覆盖五地区且独立；罗马按欧洲、悉尼按大洋洲，不按颜色混用。

- [x] **V15 旺淡季租金比例及上限**（AC5）

  **验证：** 数值场景输入标准租金30000分别应用旺季、淡季，再检查无关地区及抵押城市。

  **通过标准：** 相关地区分别33000和27000；每笔增减最多3000；无关地区不变，抵押零租，机场费无变化。

- [x] **V16 建设优惠每完整轮额度**（AC5、AC11）

  **验证：** 在建设优惠期同一玩家成功建两次，另一个玩家建一次；下一完整轮再建，包含一次远程。

  **通过标准：** 首成功按原费15%优惠最多2000；本人同轮第二次无资讯优惠，另一人独立，新轮刷新；失败不消耗。

- [x] **V17 航空促销作用范围**（AC5、AC11）

  **验证：** 在航空促销下比较付费票、免费航班及落机场费用。

  **通过标准：** 付费票按原费减30%；免费仍免费，机场费不变，不产生城市待分红。

- [x] **V18 平稳期仍有个人能力**（AC5、AC9）

  **验证：** 切到市场平稳期，对拥有有效机遇者执行一次合格优惠或奖励。

  **通过标准：** 没有资讯费用改变，已选个人机遇继续生效，不清空能力或额度。

## 三次同步选择

- [x] **V19 三次选择时点**（AC6）

  **验证：** 完成开局、资讯首次启动及资讯运行六轮的同一对局，记录新资讯和选择显示先后。

  **通过标准：** 首次掷骰前一次、资讯启动一次、六轮完成一次；第二/三次先显示新资讯，不出现第四次。

- [x] **V20 候选唯一与方向覆盖**（AC6）

  **验证：** 固定候选生成输入并观察三个阶段及多人选择，检查已经选择及永久耗尽项。

  **通过标准：** 每组三个不同项，至少两方向；本人已选/永久耗尽不再提供，不同玩家可选同项；成长型条件明确。

- [x] **V21 全局一次重选与迟到确认**（AC6、AC7、AC21）

  **验证：** 本人未提交时换一组并立即重放原请求，尝试确认旧候选；下一阶段再次重选。

  **通过标准：** 全组三项替换，排除旧三项/已选；只扣本局一次，重复/旧候选不生效，不延长时间。

- [x] **V22 共享三十秒与本人身份**（AC7、AC21）

  **验证：** 多人同时选，尝试用他人选项及身份操作；固定时钟比较不同玩家提交/重选前后的截止时点。

  **通过标准：** 同一个30秒决定；只有本人候选可操作，旁人提交不使本人合法请求过期；无效及重选不续时。

- [x] **V23 提交锁定及统一公开**（AC7、AC9）

  **验证：** 一人先提交，查看所有连接视图和现金；其余人完成或等待到期。

  **通过标准：** 本人锁定，他人只见完成状态；选项及即时奖在统一完成后才公开并应用，一次阶段一次生效。

- [x] **V24 到期默认及边界竞态**（AC7、AC21）

  **验证：** 有人已提交、有人重选但未提交；使共享时钟到期并投递一条迟到请求。

  **通过标准：** 已提交保持；未提交取当前左端项；迟到请求拒绝，到期补齐一次，不多发奖或重新开始时限。

- [x] **V25 选择中出局或终止**（AC8、AC18、AC20）

  **验证：** 按原生命周期移除参与者或房主解散，包含全员完成前只剩一人情形。

  **通过标准：** 被移除者不获未生效能力；该终止先结算，未统一生效结果不补发，不再抽新候选。
