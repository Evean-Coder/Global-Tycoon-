## 架构概览

1. 扶持模块负责历史资格、有效回合计数、只读候选与购买计划。
2. 原骰子/购地/回合完成出口记录真实机会，所有产权获得出口统一更新曾拥有标志。
3. 原购买核心承担费用、产权、上市和圈额度，扶持条件组合后统一提交。
4. 本人快照与客户端提供自愿入口、真实进度及确认，不新增阶段或时限。
5. 原动作回执、记录回放及版本机制保证重复处理、恢复和旧局兼容。

## 2. 状态与计数模块

新增 `src/propertySupport.js`，由gameLogic的有效回合完成、购地决定处理及城市所有权变化路径调用。

核心玩家字段：`everOwnedCity`、`missedPurchaseTurns`、`processedTurnId`、`eligible`、`used`。新局规则字段 `propertySupportRevision`；旧局不补计历史。

核心接口：

- `recordPurchaseOpportunity(state, playerId, turnId, offer)`：记录真实可负担且可购买的机会，拒绝时归零；报价预览不是机会。
- `finishEligibleTurn(state, playerId, turnId)`：先查解锁、从未置业和有效骰子回合标志，再更新一次计数。
- `supportCandidates(state, playerId)`：只读生成最多三城，不预留库存。
- `quoteSupportPurchase` / `applySupportPurchase`：原购地费用/产权校验与扶持资格组合；重新核对现金、库存、圈额度和revision。

所有获得城市的正式路径更新历史标志，不能只查当前城市列表。计数不依赖客户端、骰子按钮点击次数或单纯回合序号。

## 3. 扶持操作流程

第6个有效回合完成后标记资格；在下一次本人正常待掷骰阶段显示“置业扶持”只读进度和购地入口。不开新的强制阶段、不增加倒计时。玩家可暂不使用、保留资格；查看或取消不消耗次数。

购买仍通过原动作派发通道的新类别，使用服务端报价；提交成功原价扣款、产权变更、上市初始化、圈购地数+1及扶持使用标记一次性完成。与主动经营次数独立，不因查看扶持刷新本回合经营机会。

其他玩家先购买候选城市时，本人的报价失效，更新候选后重新确认；不自动换成另一座扣款。没有库存、现金或圈额度时展示原因。掷骰后本次操作入口收起，资格继续保留到下次正常回合。

封盘、自救、拍卖、交易确认、机遇/路线选择和监狱冻结决定期间不可执行；重连恢复同一资格，旧回执不能重复置业。

## 4. UI与隐私

本人可见进度“无有效置业机会 4/6回合”、触发条件与具体限制；其他玩家只看到成功购买的公共产权/事件。界面明确原价、扣款后现金、圈购地剩余和一次性使用说明。非资格玩家不展示可提交按钮。

新增入口使用统一前端组件；规则目录记录真实参数，示例从已批准规则计算。服务端拒绝原因明确区分库存变化、额度、现金和资格。

## 5. 文件与验证

修改state/gameView/gameLogic/assets/stocks中的相关产权入口；新增propertySupport；actionValidation与server原通道接入；client及规则目录新增提示。记录与回放包含计数/标记及成功事件，旧局回放按原版本处理。

指定场景：第5/6次；购地未解锁；有钱拒绝归零；无钱机会；历史拥有后出售；拍卖/受让获得城市；监狱/冻结/飞行；重复回合；没有库存/圈额度；候选抢购；失败原子性；重连；截止；与主动经营共存。先执行有限状态测试，再少量联机验证，不运行大量整局。

六回合、拒绝归零、前三低价城市及展示时点以已批准Spec为准；尚未经过实际引擎及联机验收。


## 正式交互流程 I1–I6（已确认）

审批记录：用户明确选择确认I1–I6，进入技术决策。

- I1 机会与计数：正常骰子移动时记录解锁状态；出现有效购地决定时保存实际可负担性，拒绝则当回合归零，购买成功则永久失去资格。落点/费用流程完成后在回合出口最多累计一次；第六次标记eligible。自救挂起不视为已完成，恢复后继续原回合标识。
- I2 展示：下次本人正常待掷骰读取self.propertySupport，显示真实进度、原因、最多三城报价、扣后现金与圈剩余额度。入口自愿打开，不建立强制阶段，不新增时间；无库存或资金不足仍保留资格并显示原因。
- I3 确认提交：选城只改本人草稿；确认后复用sendAction。服务端沿原重复请求结果语义及截止/身份/阶段检查，再校验扶持资格、报价、库存与原购地限制，一次完成产权/上市/资金/计数。广播原购买事件及真实快照，继续同一待掷骰回合，不消耗主动经营次数或重置期限。
- I4 取消与变化：未提交返回不耗资格；候选被抢购或报价变更，失败零修改，更新候选后由玩家重选确认。不能自动替换城市。直接掷骰收起本回合入口，未使用资格保留，下次正常待掷骰再展示。
- I5 恢复与失效：结果不确定沿用同一actionId重试，不另发购买；重连先恢复权威状态。通过任何其他路径获得城市立即取消资格，旧草稿失效；旧回执不得改变新决定。私人进度不公开，其他玩家仅收到成功产权事件。
- I6 截止与记录：封盘、特殊决定不可新购；已成功产权计入原结算，未成功不得扣款。按原记录顺序保存回合计数、获得城市标志和购买动作；新局回放相同，旧局不补计历史。

I1–I6已确认。报价、帮助与页面旋转全部只读，原决定时钟及离线处理保持。
