# 棋子半速移动 Plan

## 架构与接口

现有 `playMoveAnim` 每110ms推进一格，改为220ms；`.piece` 的 left/top 过渡由0.12s改为0.24s。保留路径计算、动画generation取消、`animQueued`后续状态处理和减少动画分支。没有新增状态或Socket事件。

## 流程

原状态到达 → 原移动路线 → 每220ms逐格更新 → 原回调完成渲染 → 顺序消费后续状态。骰子动画、服务端期限均维持现有值。资源查询版本与缓存统一到v35。

## 验证

真实双人开局后有限状态驱动移动，浏览器观察逐格位置和时间；中途再到一份状态，验证排队和最终渲染。减少动画直接到终点，资产入口仍可用。缓存沿用原回归用例。
