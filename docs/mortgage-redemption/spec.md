# 抵押赎回 Spec

日期：2026-10-12。用户反馈抵押资产无法赎回，按已授权的文档自审与开发流程修复。

## 背景与需求

旧规则仅可站在抵押城市赎回，但落到自有抵押城市直接结束回合，银行也没有入口。移除赎回的落点限制，保留债务成本。

- F1 本人正常回合掷骰前，可赎回任意自有抵押城市；银行、资产行和城市详情提供入口，无需走到该城市。
- F2 显示各城抵押本金、累计利息、合计费用及支付后现金；不足现金和不在可操作阶段说明原因，不能静默多扣费用。
- F3 成功后一次扣除本金及该城利息，清除该城抵押和利息，恢复收租资格；保留产权、房屋等级及原建房落点条件，其他城市债务不变。
- F4 银行在同一决定内更新现金、负债和城市状态，保留查看位置；失败、重复、断线和快速封盘不多次扣款，不补时，不消耗主动经营次数。

## 约束与边界

复用现有赎回动作、原生前端和Node20，不新增依赖或Socket事件。不改50%本金、5%计息、抵押两座上限、出售价格、AI策略或破产规则；不开放股票、购买、建设、拍卖、自救等未完成决定中的赎回。历史可用的赎回动作保持相同经济结果。有限固定场景验证，不跑批量对局。

## 验收

- AC1 普通/快速本人待掷骰且现金足够，不在该城市仍可从三端银行、资产或详情赎回（F1/F2）。
- AC2 费用展示与服务端一致，不足、非本人、非抵押、错误阶段、报价变更不扣款（F2/F3）。
- AC3 一城本金利息准确清偿，房屋及产权不变，恢复租金，另一城债务不变；不自动建房（F3）。
- AC4 同一请求重试只扣一次；原待掷骰期限及经营次数不变，封盘优先（F4）。
- AC5 银行成功后实时更新并保留滚动；三端、原建房募资、缓存及lint回归通过（F1/F4）。
