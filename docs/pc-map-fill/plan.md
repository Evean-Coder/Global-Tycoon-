# PC 中央地图铺满 Plan

## 架构、数据与接口

- 将 `placeLandscapeSurfaces` 改为 `placeBoardSurfaces`：使用原 DOM 地块 0、11、21 的矩形和 `boardScale` 的坐标，计算中央地图边界。
- PC 矩形从 0 格的右下角到 11 格左边、21 格上边；使用背景 `100% 100%`，宽高分别拉伸，完整保留地图内容。
- 手机横屏维持原 2px 内距、cover 缩放和台账定位；PC 不改台账定位。
- 原 ResizeObserver、窗口 resize 与渲染调度继续调用统一函数；尺寸无效时等待下次布局，不写负值。
- 缓存使用 v33 与同一资源查询版本。无新增状态、事件或计时器。

## 交互流程

原渲染 → 同步响应布局 → 根据实际地块计算地图矩形 → 重定位原棋子。地图保持 `pointer-events:none`，详情继续原入口。

## 决策与覆盖

F1 用独立宽高拉伸消除 contain 留白且保留完整图片；F2 复用原尺寸监听。测试用实际开局后受控状态，检查边界、图片加载、resize、详情与资产点击，并保存截图。
