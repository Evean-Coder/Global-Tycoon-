## 执行与证据约定

验证命令采用[task第2节](task.md#2-验证命令约定)的Q-C/Q-M/Q-S/Q-B及R系列代号。QC/QM/QS/QB是待编写场景编号；一个检查可由多个断言完成，一个测试也可给多个检查提供证据，不重复相加报告数量。

- 规则场景：指定有限输入、可控时间，记录前后现金、产权、股份、债务、阶段和结果；必要时使用夹具，但注明为受控局面。
- 联机场景：真实房间、连接和合法操作，注入内部时间依赖；总计时、截止和结算使用正式流程。替换状态或假结束回调不作为连续端到端证据。
- 页面场景：记录浏览器、视口、缩放、操作、观察和截图；尺寸模拟不登记为实体手机或平板验证。
- 每项在验收报告记录状态、命令/场景编号和证据位置。通过、失败、未执行分别记录；失败修复后保留首次失败与复验。所有适用项通过才可交付。
- 只执行规定的有限场景与必要回归，不运行大批完整对局；服务器与浏览器测试按文件串行运行，避免共享监听干扰。

## A. 功能与兼容：C1–C32

- [ ] **C1 房间模式与权限（AC1）。** 在2、3、4人房间选择普通/快速，成员均见相同配置；非房主、非法模式、局中修改被拒绝，默认普通。（验证：Q-S QS01，Q-B QB01；对比各连接的房间状态与页面。）
- [ ] **C2 页面能力及旧局（AC2）。** 缺少快速能力的页面不能开始快速局且有刷新提示；旧在途局不加入总时钟，旧记录缺数据明确说明。（验证：Q-S QS02、Q-M QM03/QM12、Q-B QB06，分别输入旧能力、旧状态和旧记录。）
- [ ] **C3 正式计时起点（AC3）。** 大厅等待不消耗时长，首阶段开始即计时；刷新、重连及切后台后恢复显示不获得额外时间。（验证：Q-C QC01/QC02、Q-S QS03/QS13、Q-B QB03；保存服务端已用时间和页面恢复后的总余时。）
- [ ] **C4 双时钟与预告（AC4）。** 总余时与个人余时有不同标签；剩5/2分钟各一次预告，跨节点检查仍补齐适用预告或优先结束。（验证：Q-S QS05、Q-B QB03；跨过25/28分钟及直接跳到30分钟，核对事件次数、总余时和终局。）
- [ ] **C5 离线仍截止（AC5）。** 一人和全员离线均不延长30分钟；个人暂停与总时间分离，重连先获得已成立终局；无人清理不制造额外时长。（验证：Q-S QS13/QS14，分别断开连接后推进到截止及截止后的清理点。）
- [ ] **C6 各类个人期限（AC6）。** 快速一般决定20秒、自救45秒、初始30秒、后续20秒；每类决定均受更短总余时约束，普通期限保持。（验证：Q-C QC05、R-C；逐类检查掷骰、极地、监狱、购置、建设、筹资、飞行、股票、拍卖、出售和转让确认。）
- [ ] **C7 同一决定不延时（AC7）。** 查看、股票子面板、转让返回、报价更新、非法动作和重试不重置原期限；真正的新决定获得其时限但不越总截止。（验证：Q-S QS08/QS09、R-B1及Q-B QB03；对比决定身份与前后余时。）
- [ ] **C8 成交边界（AC8）。** 截止前已提交的购买、建设及股票成交保留；到点或执行跨截止未提交的动作无新资金/产权影响，草稿不成交。（验证：Q-S QS06、Q-B QB08；在截止前、恰好截止、截止后三个时间输入合法请求并核对正式状态。）
- [ ] **C9 转让和直接出售取消（AC9）。** 未确认转让、未成交直接出售取消，双方资产保持，卖方房屋与产权仍在；已成交转让不撤销。（验证：Q-M QM04、Q-S QS09；对比双方现金、股份及城市状态。）
- [ ] **C10 有出价的出售拍卖取消（AC10）。** 普通/自救出售拍卖最高价尚未成交时封盘，卖方保留城市，买方不扣款，卖方无银行回购收入。（验证：Q-M QM04，分别给出最高报价和自救上下文，再比较产权、现金、房级和股权。）

## C. 必须完成的端到端场景

### E1 两人快速流程（C31，辅证C3/C13/C23–C27/C39/C44）

1. 两个真实客户端创建、加入房间；房主确认快速模式，另一端看到一致配置。正式开始前等待不扣整局时间。
2. 通过正式开局流程进入首阶段，两人合法完成选择。以内部可控时间推进到5/10分钟，在安全入口完成后续初始阶段；按现有单骰流程执行有限回合，至少实际完成一次经营操作。
3. 推进到15/22分钟，合法掷骰前领取后续机会；通过合法回合交接验证一回合不会连续领取两份，选择替换或跳过后旧使用/领奖历史保持；候选仅本人可见。
4. 推进到28分钟验证未打开机会关闭。通过实际合法动作形成一个未成交决定，记录其资产快照；流程中的阶段和产权不得通过整体替换状态直接设置。
5. 推进到30分钟，接收一次权威结果，未成交事项取消，费用事实和资产符合规则；各端结果一致，旧面板不再能提交。
6. 一个客户端断线后重连，显示相同冻结结果并核对记录；成功请求结果可重查，新请求拒绝。最后清理连接和计时器。
