# 手机与响应问题复验

2026-10-09，基线9ead166。修正用户报告的手机开局、横屏布局和股票返回问题，沿用已批准规格及本次明确的整改要求。没有新增完整模拟局。

## 实际结果

- 最终限定回归28/28通过，0失败、0跳过：[日志](mobile-final-tests.txt)。包含12个服务端场景、8个股票场景、6个手机场景、缓存迁移和一个开局至回放场景。
- 手机场景使用浏览器触控：慢请求重复点按只发一次；受限存储不阻断创建；失败/未确认显示原因；断线不缓存新的开局请求；认证重连恢复房间。
- 股票市场进入转让，未编辑直接返回恢复原面板与买入草稿，服务端状态及原期限不变；可立即放弃交易结束窗口。资产来源返回资产，继续买卖入口可恢复窗口；过期返回不会关掉新决定。
- 10种视口（320×568至1440×900）验证42格名称/归属标记、无整页横向溢出及44px主按钮。568×320、812×375、884×330、932×430使用独立滚动内容区，地块不被操作栏遮住。[测量](mobile-evidence/measurements.json)，[横屏截图](mobile-evidence/layout-884.png)，[大厅提示](mobile-evidence/lobby-375.png)。
- WebSocket连接失败时实际回退轮询并创建房间；测试使用异步错误模拟网络拒绝。标准WebSocket连接由其他场景覆盖。
- v5实际旧资源迁移至v7，补种v6缓存后确认被删除；新版规则资源与离线页面壳可用。未声称执行了v6旧页面的完整迁移。
- 受影响7个JS文件lint退出0，client/server语法检查通过；浏览器pageerror列表为空。[页面错误](mobile-evidence/page-errors.json)。

## 失败记录与修正

初次6项场景3通过3失败，保留[首轮日志](mobile-browser-tests.txt)。股票夹具误用了旧规则v1，导致私有v2观察不匹配；改为当前新局v2。回退测试同步构造异常没有模拟网络错误，改为异步错误；轮询连接会持续请求，导航等待改成DOM就绪。

随后[局部复验](mobile-targeted.txt)发现重复标签定位，改为明确的真实资产入口；[中间复验](mobile-intermediate-tests.txt)5通过1失败，发现测试引用不存在的关闭按钮，改用新增只读“查看资产”入口并实际点按。最终28项全部通过；这些夹具/定位失败没有当作产品通过证据。

## 线上和限制

发布状态见[上线核对](mobile-deployment.json)。本轮仅有限公网探针，不是手机网络压力测试。此前热实例单次WebSocket回执224ms、轮询897ms，不能推断所有地区改善比例。

Render免费服务15分钟无入站流量会休眠，唤醒约一分钟，依据[官方说明](https://render.com/docs/free)。连接提示不能消除平台唤醒或用户网络延迟。实体iOS/Safari、微信内置浏览器和具体用户网络尚未实测。房间状态保存在内存，服务重启会丢失进行中对局。

离线全局暂停规则尚未改变；[候选方案](../reconnect-experience/proposal.md)涉及游戏推进规则，按用户指定ic-spec需另行批准四份文档。
