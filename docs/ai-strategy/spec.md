# 人机经营策略升级 Spec

日期：2026-10-11。状态：用户已确认按方案开发，实施及验收完成；结果见 acceptance.md。

审批依据：用户此前授权“你自己判断文档是否合理，最终的开发问我一下就行”。四份文档分别编写、自审，用户最终确认后实施本轮策略。

## 背景与目标

当前电脑能执行原游戏流程，但固定保留18000现金、按资产列表顺序投资，不飞行、不接受转让，机遇主要使用固定分数。目标是让电脑根据公开局势和本人信息比较收益、风险与回本时间，减少明显不合理的经营行为，继续适用于普通和快速模式。

采用“有限预测＋收益比较”的内置策略：比单纯调固定分数更能应对局势，计算量可控。首版继续一个标准难度。

## 功能需求

- F1 根据附近可能支付的租金、机场费、远航开支调整现金储备；高风险局势减少投入，低风险局势允许合理投资。投资后不主动制造现金欠款。
- F2 对合法买地、扶持购地、建房、促销和主动买股进行比较。考虑实际费用、资产价值变化、预期收入、机遇和剩余经营时间，允许直接掷骰。选择不依赖资产排列顺序。
- F3 股票比较公开经营报价、最近租金、房屋、待分红和持仓；缺钱优先减持收益较弱的股票，避免同一窗口卖出后买回。继续遵守本人城主上限、供应和窗口额度。
- F4 根据下一段道路的支出风险选择有价值的飞行；对转入股份报价进行判断，有利且负担得起时接受，不合理时拒绝。拍卖和直接购买计入已有房屋价值，并设置明确最高可承受价。
- F5 机遇及后续换路线按本人资产、持股、机场、剩余时间和已领取的一次性奖励判断；有实际价值提升才换路线。首版不增加主动换组选项策略。
- F6 欠款时比较卖股、抵押、拆房的收入损失与债务代价，卖股数量以补足欠款为目标；资金足够即退出。只有必要时出售城市，避免重复尝试无人购买的城市。购地募资仅在已有合法筹资手段足够且收益值得时执行，否则退出。
- F7 快速模式读取玩家同样可见的真实剩余总时限，临近封盘时按净资产考虑收益；减少来不及回本且降低净资产的投入。普通模式使用固定有限经营视野。
- F8 保留原动作校验、报价版本、调度、离线停止、重连及封盘处理。策略失败有可结束当前决定的回退，仍有合法救援资产时不因策略异常直接放弃自救。

## 非功能需求

- N1 只用本人快照与公开规则，不读未来骰子、机会牌、随机种子、其他玩家私有选择；预测是估计，不作为真实报价或胜率。
- N2 不引入外部模型、框架或运行时依赖；不改变价格、随机机制、时限、人数或真人操作规则。
- N3 一次预测最多8步、4人、42格、每步10种骰子点数，禁止递归完整对局搜索。策略同步计算的100个固定快照基准目标为单次P95不超过50毫秒，超标先缩小计算；不缩短原思考展示时间。
- N4 使用固定对照场景、有限动作轨迹、必要回归和三端联机流程验证；不启动大量完整对局。没有实际运行的检查不得标记通过。

## 本轮边界

不增加难度选择、聊天AI、机器学习、长期玩家画像或主动对外发起交易。不新增资金或作弊信息。不重写游戏引擎或离线规则。不承诺确定胜率、最优解或必胜。

## 验收标准

| 标准 | 可观测结果 | 覆盖 |
|---|---|---|
| AC1 | 同等现金下，高额租金道路和开支预告能提高储备并阻止危险投资；安全道路能允许预算内投资 | F1 |
| AC2 | 构造各自占优的建房、促销、股票场景以及全不值得场景，分别选中占优行动或掷骰；交换资产顺序不改变结果 | F2 |
| AC3 | 同价不同经营预期股票选较优者；待分红增大不会被重复计收益；城主买自己股份不会被误算成新增基础租金 | F3 |
| AC4 | 缺钱卖股数量正确且优先保留较好收益；同窗口不买回已卖股票；股数和额度全部受原规则约束 | F3、F6 |
| AC5 | 有利免费航班能选择，成本高于改善收益则不飞；飞行判断不虚构即时购买、经过起点或机场奖励 | F4 |
| AC6 | 有利转让接受、过贵/超限转让拒绝；有房城市可在合理价格竞拍，超预算立即退出 | F4 |
| AC7 | 资产/持仓差异改变机遇偏好；已领取一次性奖励不再次估值；新路线不足以改善时保留原路线 | F5 |
| AC8 | 卖股/抵押/拆房在不同损失场景下选取较合适动作；补足欠款即结束；可救援时异常回退不会直接放弃 | F6、F8 |
| AC9 | 募资满足条件可推进，不能合法筹齐则退出；募资不提交该阶段禁止的卖股操作；同城出售不无限重试 | F6 |
| AC10 | 相同资产分别在快速模式充足时间和临近封盘时做出合理差异；负债按净资产处理，总时限缺失时采用保守策略 | F7 |
| AC11 | 同一快照与记忆确定性一致且输入不变；修改私有随机状态不改变决定；非法或旧报价由原引擎拒绝且无部分修改 | F8、N1 |
| AC12 | 动作上限、失败退出、真人离线停止、封盘撤销、重开记忆隔离及调度去重回归通过；CPU基准和三端流程有真实证据 | F8、N3、N4 |

## 自审

F1–F8均有验收对应；规则修改范围为零；限定策略升级一个子项目。实现批准后才能更新完成状态。固定场景结果用于确认决策弱点改善，不能替代总体胜率统计。
