## 执行方法

逐项保存固定状态、请求前后差异、命令输出或三端截图。失败修复后复验；未执行写未验证。资金与截止检查用真实引擎和服务端入口，不能只测前端显示或复制公式。沿用Node20、现有测试工具及受控状态；不运行大量完整对局。

- [x] C4（AC2；T11）：核对低价与达到上限城市的促销费4%最高800、奖励8%最高1200及整数取整，成功扣费登记一次。

- [x] C5（AC2；T11、T14）：每个人圈最多一次、同时最多一个；新圈替换旧活动不退款；启动当前轮及下一完整轮有效，到期不多奖。

- [x] C6（AC2；T12–T13）：0/1/2次实际完成他人租金分别奖励0/1/2次，第3次不奖；本人到访、零租金、预览均不奖。
