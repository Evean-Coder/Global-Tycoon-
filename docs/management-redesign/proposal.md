# 主动经营与机遇体验重做提案

日期：2026-10-13。用户要求完整开发文档先行，文档自审；本文件为规则澄清与现状审查，不是已实现或已上线规格。第152轮旧故障按用户要求停止排查。

## 用户明确提出的改动

1. 删除棋盘中央台账的主动经营按钮，只保留与掷骰按钮同一操作区的入口。
2. 每回合强制进行主动经营。
3. 经营窗口先选择三个选项之一，再进入目标城市子视图。
4. 改善当前机遇效果弱、缺乏趣味的体验。

## 当前实现与问题

| 项目 | 现行行为 | 需要整改的原因 |
|---|---|---|
| 入口 | 台账及底栏均有经营入口，手机横屏隐藏底栏经营按钮 | 删除台账前必须恢复横屏底栏，否则会失去唯一入口 |
| 经营流程 | 三种操作及所有报价城市在同一弹窗长列表排列 | 选项与目标混杂，手机浏览负担大 |
| 正常回合 | 最多成功经营一项，可直接掷骰或结束回合 | 与新强制经营要求不符，必须增加服务端推进条件 |
| 促销 | 地价4%费用、最高800；当前和下一完整轮内，他人偿清正额租金后奖励地价8%、最高1200，最多两次，每圈启动一次 | 低玩家数或位置不合适时很容易零触发；没有清楚展示活动期间或回合结果 |
| 主动买股 | 一次一城1–2股，1%手续费，每圈最多4股、同城2股 | 强制经营后可能很快用尽额度；买入原因和回报缺少直观说明 |
| 远程建设 | 标准建房费145%，优惠后最低135% | 高额溢价削弱建设吸引力；只显示支出，没有展示建设后租金与经营变化 |
| 已选机遇 | 12项，大部分靠圈结算、落点或少数资格触发 | 数值上限、使用事实与长期路线没有形成足够鲜明的操作反馈 |

以上根据当前源码审查，不是新胜率或真人体验实验结论。

## 已确定的界面设计

### 唯一入口

PC、平板、手机竖屏及横屏统一在操作栏显示「主动经营」「掷骰子」。台账只保留经营进度和活动的只读摘要；不能再从台账进入经营窗口。低宽度优先保留这两个按钮和决定倒计时，辅助查看入口可放到更多菜单。

### 两级选择

第一层展示三个清楚的经营类型卡片（现有类型为促销、买股、建设），各卡显示用途、当前可执行城市数量和本回合条件。第一层不展开全城列表，也不扣钱或消耗次数。

点击某一类型进入第二层，只显示该类型城市。城市条目显示名称、真实费用、操作后现金、执行后的实际变化，以及无法执行的文字原因；先选城市再确认，不采用点选即付钱。

买股的1股/2股在所选城市中调整，不再将同一城市重复列成两行。返回第一层保留同一回合的有效草稿；任何状态变化都按服务端新报价复核。交易成功显示结果，回到底栏完成掷骰。

### 强制经营的基础条件

正常回合且本人操作时由服务端判定经营是否完成；不能仅将掷骰按钮禁用，因为旧客户端、重复请求或电脑玩家仍可能绕过。结束回合也必须遵守同一条件。机遇/路线选择、监狱、冻结、自救、拍卖及交易确认先沿其自身流程，不能与强制经营弹窗重叠。

退出查看窗口、切换经营类型和返回不等于完成经营；倒计时、断线恢复、快速封盘及AI都必须有明确处理规则。先完成初始机遇或后续路线选择，再进入经营决策，不允许旧回执锁住下一阶段的控件。

## 趣味改进设计原则

### 主动经营应有三个不同的决策理由

- 短期促销：能影响接下来的若干回合，展示期限、受影响目标及已获得的收益；减少「交钱后完全没有动静」的体验。是否延长期限、扩大作用范围或改变奖励形式，需要独立数值表。
- 中期投资：城市列表展示经营状态、实际收入历史、待分红与买入后持股；不把未来股价或分红写成保证收益。
- 长期建设：展示房级、建设前后租金及费用，让玩家知道自己改变了什么；重新检查现有45%溢价是否适合强制经营节奏。

强制经营不能同时依赖极少的每圈次数，否则很多回合只能自动放行；每回合行动次数与每圈额度必须分列设计。现金支出、收益期限、投资风险和资产增量需并列比较，不以「全面提高奖励」代替平衡。

### 强化应改变选择，而不只是多领少量现金

若本轮包括12种强化重做，每种都应描述：触发条件、影响哪类决策、可观测结果、限制及失效条件；避免同名重复小折扣。保留可以用操作反馈解释的地产、投资、航线与防御路线，增加与经营类型之间的明确联系。

数值方案必须比较同一资金、同一资产下的低/高命中、短/长视野及临近封盘场景；分红、城主收入和银行补贴分开计，避免重复计值。现有一次性奖励、股票4股城主限制与骰子规则不能因界面改版无说明改变。
