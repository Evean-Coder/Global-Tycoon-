# 一次预算选购 Spec

2026-10-13：用户已明确“同意一次预算选购的开发草案”；金额与混合组合按已呈现草案采用20,000。文档依据自审授权细化，开发已授权，禁止推送。

## 功能与约束

- F1 新局默认启用预算扶持：原六回合/从未拥有城市资格保持，平时隐藏，仅在本人正常掷骰前资格生效时弹窗；取消不耗资格，同回合广播不反复弹，下个正常回合可再次提醒。
- F2 一次选择一座或多座未售城市，总价≤20,000、≤现金、数量≤本圈剩余四城额度；原价自付，不送现金、剩余预算不结转，成功一次永久结束。
- F3 所有普通未售城市可选，排除纽约/上海；仅当其余城市全部当前有归属才开放未售纽约/上海。现金不足、预算不足或出售占用不是开放理由。
- F4 全部选择一次校验和提交，失败零扣款零产权，库存/报价/现金变化先更新再确认，重复请求只成功一次。新增查看不刷新决定期限，不耗主动经营次数。
- F5 老v1局保留旧三候选单城规则；新v2私有快照、AI和记录回放一致，旧回执不能关闭新窗口。

## 验收

AC1/F1：无资格常态不显示入口/进度；仅本人收到一次弹窗，旁观者没有私有提示。
AC2/F2：一高/多低/混合、超预算/现金/圈额度/重复城市校验，费用产权上市及圈次数一致。
AC3/F3：普通池、全部售完后两高价开放、仅剩一高价、普通城重新归银行、占用/资金不足边界。
AC4/F4：抢购及迟到回执、原子失败、重试、取消、重连、封盘验证。
AC5/F5：旧局、AI、回放、三端、缓存和必要有限回归，不跑大量完整局。
