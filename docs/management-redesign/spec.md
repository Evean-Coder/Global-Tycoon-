# 每回合经营与机遇重做 Spec

2026-10-13。用户已选择「可执行时必须完成一项，全部不可执行则说明并放行」「三类经营及12种强化全部重做」，并要求按要求执行。沿用用户授予的文档自审权限，本轮文档先行、随后开发。方案与验证结果分开记录。

## 目标
正常回合提供有实际经营影响的必选决策；操作先分类型再选目标，适合手机。三类动作分别侧重短期客流、中期股权、长期租金；强化扩大经营路线差异。

## 功能需求
- F1：中央台账移除经营按钮，只展示进度；四类屏幕均在掷骰所在操作栏保留唯一经营入口。
- F2：正常待掷骰且存在合法、现金可负担项目时，必须成功经营一项才可掷骰。结束回合同样受限。完成后不能再经营。全部不可执行时展示原因并允许掷骰；取消、返回、失败不算完成。不提供免费替代动作。自救、冻结、监狱和交易等专用阶段先执行原流程，恢复正常待掷骰后重新判定。
- F3：第一层三个类型卡片显示用途及可执行城市数；第二层只列该类型城市，显示真实报价、操作后现金、收益条件与不可用原因，买股按城市调整1/2股。确认才提交，返回可重新选类型。报价变动要看新报价后再次确认；旧回执不能关闭新窗口。
- F4：经营与掷骰共享同一次决定时限，普通90秒、快速45秒，打开/返回/无效请求不续时。超时仍有合法项目时，服务端选择最低总支出（并按类型、城市、股数稳定排序打破平局）执行一次并自动掷骰；无项目直接掷骰。展示此默认处理。封盘优先，不额外购买。电脑玩家同样必须经营，必要时采用最低支出方案。
- F5：三类经营按下表执行。每个人正常回合最多成功一项；新规则取消经营的每圈促销与买股次数限制，原起点股票窗口额度独立。
- F6：12种强化按下表执行；实际生效、减免、奖励记录可核对。换路线不重置当圈额度、机场访问事实或一次性领取事实。
- F7：新开局采用新规则，已存在的旧版本对局保留原数值及可跳过规则；快照、回放、规则说明、AI使用相同版本。

## 三类经营数值
| 类型 | 支出与限制 | 收益与风险 |
|---|---|---|
| 限时促销 | 自有非抵押城市，地价3%，最高600；同时仅一个活动，活动结束后才可重新开展 | 当前及后续3个完整轮内，其他玩家偿清正额租金后，银行另奖地价10%、最高1500，最多3次；无客流可能零回报，无本金返还。产权变化、抵押、出局、封盘撤销；不进入分红池 |
| 主动买股 | 一次选择一城1–2股，整笔1%手续费；市场20股、城主4股上限继续有效 | 获得股权及真实分红；展示当前经营报价、近3轮收入、上次每股派息，不保证未来盈利 |
| 远程建设 | 自有非抵押且未满4级城市，加1级；标准建房费115%，建设优惠合计最多减30个百分点 | 永久提高租金与城市标准估值，显示前后房级及标准租金；落点建设仍按原标准费用及优惠 |

## 非功能要求及边界
- N1：服务端报价、资格与一次提交为准；金额沿用整数取整，无重复扣款/奖励。浏览帮助不改变状态。
- N2：沿用原生前端与现有服务端；支持触控、键盘、缩放，经营窗口可滚动，关键按钮和计时可触达。
- N3：有限固定场景与必要回归；不运行大量整局，不把受控数值验证称为总体胜率平衡。
- 不改棋盘、单骰、普通买地、股票市场供给、抵押、30分钟封盘和后续机遇出现频率；不恢复第152轮单独排查任务。

## 验收标准
- AC1/F1：台账无经营按钮，桌面/平板/手机竖横屏底栏有且仅一入口。
- AC2/F2：有项目禁止跳过、完成一项才放行；无城/低现金/满级/满股等全不可用状态允许掷骰并说明原因。
- AC3/F3：类型→城市→确认完整可用；返回不扣款，买股不重复城市，旧报价拒绝后可重试，旧回执不关闭新窗口。
- AC4/F4：超时最低支出经营和掷骰一次完成；伪造超时被拒；同决定不续时；快速45秒受总时限截断；AI不能跳过必做项。
- AC5/F5：逐条验证三类费用、次数、持股上限、促销期限/撤销/欠租和建设前后收益。
- AC6/F6：12项固定输入输出验证，含优惠叠加上限、圈刷新、机场重复、一次领取和换路线额度。
- AC7/F7：旧版本数值不变，新版本快照/重放可识别、AI评价适配，私人候选不公开。
- AC8/N1–N3：必要单元与联机浏览器场景、三端布局检查、lint；真实结果写验收报告。
