## 已发现并修复

1. 模式切换等待回执时，旧状态会让单选卡暂时回退；展示现在保留待确认的真实请求值。
2. 扶持查看弹窗缺少关闭按钮；已补取消入口。
3. 促销欠租偿清发生在轮次末时，奖励必须先于到期清理；已调整顺序。
4. 固定操作栏在手机竖屏及平板遮挡地块；改为独立区域，新增几何重叠检查。
5. 新经营流水统计引用了错误变量，导致终局记录失败；已修复并复验终局/记录9项通过。
6. 旧完整场景未处理route_choose；旧大厅测试仍期望离线成员允许开局；测试按现行规则更新，未修改这两条生产规则。
