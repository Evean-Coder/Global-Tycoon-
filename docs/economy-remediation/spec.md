# 长局与投资整改候选检验 Spec

2026-10-05。用户要求“整改长局问题、检查投资策略与收益结构”。本周期将问题定位、隔离候选与有限验证做成可审批结果。测试部分沿用自行审批授权；生产规则候选尚待用户批准，禁止直接部署或改写旧证据。

## 目标与范围

- F1 从真实规则及旧摘要拆出起点补给、机遇、租金银行补足与支出，给出长局与投资表现的具体依据。
- F2 在独立测试策略中修正零收益优势也买入、无必要折价减持、分散资格多买的问题；旧冻结策略与旧结果保持原样。
- F3 隔离验证唯一规则候选：已完成完整轮0–39奖励10000，40–79奖励5000，80及以后奖励2000；刷新、股息和个人机遇保持原值，不新增按钮或强制终局。
- F4 最多3组共同种子原规则/候选正常开局对照，共6条轨迹；同组只有起点奖励变化，统一原冻结策略。每条最多250完整轮/6000动作，程序活动累计最多3分钟，预算中断缺口列明，不续开局。
- F5 给出每组终局/截断、轮数、胜者与实际起点注入，并单列策略夹具和投资现金回本；失败不能算通过，少量对照不宣布总体胜率公平。

## 约束

N1 原30源码指纹、旧数据与当前联机交互保持；候选只在受控执行器中编译。N2 新策略独立版本，只看本人视图，不回写原正式策略。N3 总额度/输入预登记、活动落盘、无重置、无逐动作模型调用，无大型统计或多代理。

## 不做

本周期不改正式股票价格/分红、不削减全部机遇、不改获胜规则、不恢复上千局、不把正常开局截断当胜负、不把估算回本当保证收益。生产候选要经过批准后另行实现和界面告知。

## 验收

- AC1（F1）真实资金来源、股票本金/股息/未实现价差区分，具体数字可复算。
- AC2（F2）无收益不买、必要减持按银行报价、分散只买缺少的一股、累计额度/储备/城主上限/接受转让合法；旧策略不变。
- AC3（F3）39/40/79/80边界与旧规则兼容核对；真实引擎中发钱、文本和后续结算一致，不用事后扣钱模拟。
- AC4（F4）输入、种子、策略、每条起始摘要和唯一候选差异可追溯；数量、轮数/动作/180秒上限以及缺口如实列出。
- AC5（F5）实际报告区分节奏效果、投资规则结构、机器人修正；自然局只报真实胜者，候选未达改善条件就不推荐上线。
- AC6（N1–N3）必要工具验证与静态检查，原源码/旧证据保护核对；提供生产修订的具体规格供审批。

自审：测试范围覆盖上述AC，通过。该自审不等于用户批准生产规则。
