# 手机仅横屏游玩 Spec

2026-10-13。用户明确删除手机竖屏对局逻辑，进入游戏尝试自动切换横屏，失败时以最高优先级弹窗要求开启自动旋转并横放手机后继续。沿用文档自审授权，承接本轮「完成先不推送」指示，仅本地开发。

## 功能需求
- F1：彻底移除手机6×7竖屏棋盘、竖屏信息标签页、竖屏专用资产/地图槽和竖屏底栏逻辑。游戏棋盘统一为42格环形；手机实际游玩使用左棋盘/右信息/底操作横屏布局。
- F2：手机进入对局、重连/刷新恢复及回放时尝试锁定横屏；浏览器支持时使用屏幕方向接口。房主竖屏点击开始时先处理横屏，成功横屏前不发开始请求。弹窗提供用户点击的全屏横屏尝试；不能自动打开系统设置，不把接口返回成功当成实际已横屏。
- F3：手机未横屏时立即显示最高优先级、不可关闭的横屏提示，说明开启自动旋转/关闭竖屏锁定并横放手机；拦截背后所有弹窗、触控和键盘操作，不能点遮罩或按Escape跳过。实际横屏后自动解除；再次竖屏立即恢复阻挡。
- F4：PC及平板正常使用，手机大厅/房间仍可竖屏浏览。旋转只改变本地显示，不发游戏动作、不重置服务器期限、不丢股票/经营草稿。全局30分钟计时照常；客人进入已开局房间旋转期间原决定时限照常。
- F5：同步PWA方向声明、本地资源版本和缓存；无接口、接口拒绝、超时均可通过手动旋转继续，失败不得造成黑屏或无限等待。

## 约束与范围
沿用原生前端，不改服务端数值或规则，不添加运行时依赖。使用有限受控回归；实体手机未测应明确记录。系统自动旋转无法由网页直接开启，提示提供操作说明。

## 验收
- AC1/F1：生产源码无compact棋盘分支/竖屏信息栏，42格环形唯一；横屏图片铺满和经营入口保留。
- AC2/F2：手机竖屏房主点击开始不发送请求，横屏后恰好一次开始；客人/重连/回放进入时提示及时出现；方向接口成功、拒绝、缺失均有可核对结果。
- AC3/F3：横屏提示压过机遇、路线、股票、通用和规则弹窗，背景inert且动作守卫生效；Escape/遮罩/Tab不能绕过。横屏实际成立才恢复。
- AC4/F4：竖→横→竖重复检查，草稿、快照与期限不因浏览变化；平板竖屏/PC保留可用。
- AC5/F5：缓存升级、PWA声明、有限浏览器/单位回归和lint通过，真实证据记录；本轮不推送。
