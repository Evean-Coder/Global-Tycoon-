# 快速对局：半小时目标提案

> 当前进度（2026-10-10）：四份文档均已批准，48项任务已完成，本地验收见[acceptance.md](acceptance.md)。未推送、未Render部署。下文保留历史提案，历史待确认文字不代表当前实现状态。

更新：2026-10-09。阶段：ic-spec 需求澄清；未批准正式规格，未修改实现。

## 已明确的用户目标

用户希望快速模式的游戏时长控制在半小时左右。此前提出的45分钟只是候选建议，现以约30分钟为目标。

## 背景与目标及计时方向（已确认）

现有游戏以最后一名存活玩家获胜，完整对局可能持续较久。增加房间可选的快速模式，使2–4名玩家能安排约半小时的一局，保留现有棋盘、经营内容和基本操作含义，通过明确的计时结束和资产结算完成对局。

目标时长从服务端正式开始对局起计算，包含初始机遇选择和游戏中的决策等待；大厅等人及结算页停留不计入。提前产生最后一名存活玩家时可以提前结束。正常服务运行期间，到达时限不能因等待完整轮次、连续拍卖、交易或断线暂停而无限延后。

## 计时方案

### A：30分钟封盘（已选择）

- 正式开局后计时30分钟，三端显示剩余总时长。
- 剩余5分钟及2分钟给出结束预告。
- 到时停止接受新的经营动作，结清已经成立的收益并计算排名；不等整轮走完。
- 未成交转让、未完成拍卖、资金不足自救等结束边界另行逐条定义；不能直接套用正常回合的默认处理，导致封盘后再推进或误扣钱。
- 断线不延长总时限；服务重启后的对局恢复不纳入未经批准的存档功能。
- 30分钟指服务端封盘时刻；客户端收到结算存在网络传播延迟，不承诺所有手机恰好同一秒显示结算。

### B：30分钟后最多一分钟收尾

- 30分钟进入收尾，最多到31分钟封盘。
- 收尾阶段允许完成哪些当前决定需要进一步规定，不等待完整轮次，也不能开启无限连续处理。
- 好处是给正在操作的玩家短暂收尾机会；代价是边界和提示更复杂，实际结束时间不是固定30分钟。

## 功能需求 F1–F8（待确认）

### F1：房间选择快速模式

房主开局前可以选择普通模式或快速模式，所有房间成员能看到选择。快速模式目标为30分钟；开始后不可修改模式或总时限。普通模式保持现有获胜与时间规则。

### F2：公开总计时与预告

从服务端正式开局开始计算30分钟，包含初始机遇选择。大厅等待不计入；个人决定、动画、断线及原有离线暂停均不延长总时限。三端显示剩余对局时长，并与个人操作倒计时清楚区分；剩余5分钟和2分钟时提示即将按净资产结算。全员离线时到期仍可封盘，重连查看结算。

### F3：快速模式的决定时间

一般决定最多20秒，包括掷骰、购买、建设、飞行、股票操作、单次竞拍响应和交易确认；欠费自救最多45秒，公共机遇选择仍为30秒。三端显示实际剩余决定时间，超时沿用各决定已经定义的默认处理。查看资料、返回弹窗、无效输入及同一决定内的重试不重置期限；出现新决定按该类上限计时，但不能越过整局结束时间。

该条只适用于快速模式。没有确认新的离线推进规则前，原离线暂停行为可以继续存在；它不能停止快速模式的整局计时。短决定时间不表示已经解决网络延迟。

### F4：30分钟结束边界

到时立即停止接受新的游戏动作，不额外完成当前回合或完整轮次。已经成立的购买、费用、股份与产权转移保留；未成交转让、未完成拍卖和未提交订单取消，不能仅凭已经出价或本地点击强制成交。需要保留或恢复未成交资产的正确原归属，不能因进入出售流程就丢失资产。此前已经确认的破产不撤销。

欠费自救到时不再自动出售或强制破产：以已经发生的负现金和现有资产计算净资产。未完成的机遇选择取消，尚未生效的选择不补发奖励。封盘后不追加新的租金、起点补给或回合结束费用，只结清已经成立的经营收益。

### F5：净资产结算

封盘先结清已有待分红，再以同一份结束状态为所有存活玩家计算：

净资产 = 现金（可为负数） + 城市标准价值 + 机场标准价值 + 持股结清股息后的报价价值 − 抵押本金 − 累计抵押利息。

城市标准价值沿用地价加各级标准建设价值，机场标准价值沿用每座15000。待分红只结清一次，不同时作为现金和待分红重复计入。单纯抵押借款不能虚增净资产；库存未发行股份不计入玩家持股。

### F6：胜负与同分

存活玩家按净资产从高到低排名，相同净资产并列；已出局玩家排在存活玩家之后，按现有出局先后规则列出。净资产并列最高时展示共同第一，不能默认用座位顺序打破平局。30分钟前仅剩一名存活玩家时提前结束并由其获胜。

### F7：资产与结算解释

快速模式显示用于排名的净资产，并说明现金、地产、机场、股票、抵押本金和利息的组成，避免把当前未扣债务的展示总资产当作最终排名。结算页显示结束原因、实际对局时长、各人净资产明细、并列情况及取消的未成交事项。

### F8：结束与回执一致

重连、重复超时通知、迟到动作及迟到回执不能重复结清收益、复活订单或重新开启已结束对局。以服务端是否在截止前合法接受并完成动作处理为准；手机点击时刻不保证成交，等待中的玩家最终能核对执行、取消或到期拒绝结果。
