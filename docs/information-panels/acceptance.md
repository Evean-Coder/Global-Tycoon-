# 资讯面板、阅读状态与规则定位验收

2026-10-14。已按用户界面整改及文档自审授权实施，尚未推送。

## 已实现

- 独立环球资讯位于资产台账左侧，两个等宽等高面板一起在地图中居中，各自内部滚动；保留棋盘42格、玩家点位、地图铺满及底栏顺序。手机短横屏棋盘仍可独立滑动到中央阅读区。
- 资讯显示真实地区、剩余完整轮、下期预告、本人相关城市/机场和远航费用。此次增强可见性，现有事件数值保持；数值机制强化尚待设计和审批。
- 同一对局的快照更新保留资讯/资产/资料的展开状态、位置及有效焦点，原渲染器继续更新现金、产权、报价与许可；新对局清除阅读记录，本人新决定和终局仍优先。资产/城市详情在成功抵押/赎回后保持打开，用户手动关闭。
- 银行/资产、地块/飞行、股票、经营、扶持、初始机遇/后续路线、资讯、自救的规则速查定位对应主题或子段；返回保持股票草稿与原期限。
