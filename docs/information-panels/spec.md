# 资讯面板、阅读状态与规则定位 Spec

2026-10-14。依据用户界面整改授权与文档自审授权通过；仅本地开发，不推送。

- F1：环球资讯独立放在中央资产台账左边，两块等宽等高、共同居中，匹配纸色地图风格，内容分别滚动；地图仍铺满，地块和棋子可操作。PC、平板、手机横屏可读，手机竖屏限制保持。
- F2：资讯突出当前事件、适用地区、剩余完整轮、下一轮预告和对本人城市/机场的影响，远航费用分列；使用真实公开资料，不虚构效果，不改数值。
- F3：其他玩家操作和同一界面的快照更新保留资讯影响说明、资产详情等展开状态、阅读位置和有效焦点；金额、权限、报价继续实时更新。新对局不沿用旧阅读状态，本人的新强制决定或终局按原流程优先。
- F4：各界面的规则速查直接展开并定位对应主题；股票→股票、银行/资产→银行、建房/购地→地产、飞行/机场→机场、经营→回合经营、扶持→置业扶持、机遇/路线/资讯→机遇或资讯、自救→自救。关闭规则不丢原草稿、不提交动作、不延时。

AC1/F1：三类视口两个面板左资讯右台账、尺寸一致且处于地图内，独立可滚动，底栏和地块入口可用。
AC2/F2：真实事件、地区/倒数/本人影响/预告/远航费用可核对，无事件及旧局明确展示。
AC3/F3：扩展后由另一玩家触发广播，展开/阅读位置保持、现金和权限更新；本人新决定正确替换，关闭后不重新打开，新局清除。
AC4/F4：各入口展开匹配主题和子段，返回保留交易草稿，无额外请求或期限改变。

沿用原技术栈，不新增事件和依赖；有限浏览器与必要回归，不运行大量整局。世界事件强度、三路线数值另走方案审批。
