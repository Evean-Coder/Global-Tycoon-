# 三条主动经营路线平衡 Spec

日期：2026-10-13。状态：方案自审，等待最终开发确认；未修改正式规则。用户要求完整文档自审，最终开发再询问。本轮不推送。

## 背景与目标

当前每回合远程建设可快速升满房级，优惠叠加时实际成本可低于新增标准估值；促销依赖他人落点，买股每次仅1–2股且收手续费。将路线区分为短期现金、投资分红和长期地产，限制持续建设速度并保留有条件的不同选择。

## 功能需求

- F1：每名玩家远程建设首次符合条件即可使用；成功后需再完成3次本人起点结算才可再次使用。所有城市共享冷却。同时，目标不能与本人上一次成功远程建设的城市相同；必须先在另一城成功远程建设，才能回到该城。失败、取消、等待、普通落点建房、换路线或城市买卖均不清除这两个限制。仅有一城时，首次远程建设后可继续普通落点建设，不能重复远程建设同城。
- F2：远程建设仍增加一级、最高四级，按目标房级采用标准建房费150%/200%/300%/350%的名义费用；沿用原优惠来源、顺序和总计最高30个百分点的限制，实际费用最低150%。只有实际减额非零才消耗优惠；一级已在下限时不浪费优惠。普通落点费用不改，不能靠叠加优惠在无新增经营收入时凭空增加净资产。
- F3：以“经营订单”替代限时促销。每个人圈最多一单，同时仅一单；选择自有非抵押城市或自有机场，预付目标基础价格10%、最高1000。后续两次本人回合开始各获得基础价格12%、最高1500。产权变化、城市抵押、出局或封盘取消未领取收入，不退已支付费用。各次收款只生效一次，不依赖别人踩格。
- F4：主动买股一次一城1–4股、无额外手续费，不新增圈购股限制；市场20股与城主4股上限保留，起点股票窗口额度独立。只对本圈主动买入且仍持有的股份，在城市正常起点派息时额外奖励其基础现金股息30%，本圈最高1500；未成交、零股息或亏损不补贴。本人下一次起点结算完成后终止该圈资格。
- F5：主动投资奖励不复利，与稳健股息分别按基础实收股息计算；转让、清算、终局派息不发主动投资额外奖。出售/转让/强制减持优先消减奖励股份，受让方不继承。正常股价、分红池和本金没有保证收益。
- F6：继续每个正常回合最多一项，可以放弃；主界面三路线→子界面目标→确认。常显建设还需经过起点次数、订单费用/两次收入/取消条件、股票股数额度/分红奖励资格，数据以本人服务端报价为准。
- F7：新局启用规则版本v4，旧v1/v2/v3局保持旧经营与原报价。AI、规则、三端和回放同步适配。H1只减远程服务加价，不能绕过冷却；其他机遇原数值不变。

## 非功能需求与边界

沿用现有原生前端、整数金额、Socket动作与原产权/交易校验；失败零修改，重复请求不重复建设、收订单或奖励股息。三端可读可触控，纯查看不延时期钟。自救无时限、快速整局30分钟、地图/台账、置业扶持预算草案保持各自状态。

不保证三项在所有局面收益相同；用有限固定场景检查收益结构、现金压力和无交易套利，不运行大量完整局、不宣称总体胜率平衡。

## 验收标准

- AC1/F1：首次可用，成功后的0/1/2次起点结算不可用；第3次后另一城可用、原城仍不可用。另一城成功后原城可在下一冷却结束后使用。失败/取消、普通建设、旧别名、换机遇和产权变化不重置；单城原因、重连、回放与重复请求一致。
- AC2/F2：四个目标房级无优惠分别150%/200%/300%/350%；优惠组合保留30个百分点上限，实际不低于150%，零减额不耗优惠。普通落点费率不变，无租金即时结算不产生正的建设净资产差。
- AC3/F3：订单两次本人回合开始各支付一次；每圈/同时限制、取消、机场、冻结/监狱回合、重连与旧回执均一致；终局不凭未赚取收入增资产。
- AC4/F4/F5：股数1–4、无新增圈额度、市场20/城主4、真实报价可核对；奖金仅实际基础派息、正常起点、有效挂牌和仍持有的标记股份，30%/1500无复利，买后即卖无奖励。
- AC5/F6/F7：三端主子窗口、原因与剩余额度、两模式、AI决策、版本和回放一致；旧局用原价格与规则。
- AC6/N：有限固定数值模型至少存在订单、投资、建设各适合的局面；明确风险和资本差别。实施后再跑引擎/联机/缓存/lint验证，不把模型通过记为开发通过。

## 自审

F1–F7均有验收归属；订单、奖金为有限银行奖励，已有总额上限；建设最低成本消除原已知无客流估值获利。按当前授权完成文档自审，最终开发须用户确认。
