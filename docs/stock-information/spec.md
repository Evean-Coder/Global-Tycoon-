# 股票查看入口与本人持股明细 Spec

2026-10-13，依据用户反馈；沿用文档自行审查授权，四份文档先于实现。当前仍暂停推送。

## 背景与目标
手机侧栏“股票市场”在非交易阶段只提示不能交易，资产总览缺少具体持股。目标是随时查看市场和本人投资，同时明确查看与交易的区别。

## 功能需求
- F1：对局中的股票市场入口可查看全部城市当前报价、归属、市场剩余、本人持股及经营/报价/股息资料；未上市、抵押和清算状态明确。
- F2：非本人起点交易窗口显示只读市场，提示原交易时机，提供关闭及资产入口，不出现买卖数量、确认、放弃交易或转让操作。浏览不发送游戏动作、不影响期限与资金。
- F3：本人实际交易窗口仍通过该入口显示原交易界面，保留数量、草稿、滚动、报价确认和回执流程。只读查看结束不会清空交易草稿；新强制决定优先于查看。
- F4：资产总览新增银行同款持股明细，显示持股合计、当前报价总值，以及每城股数、每股报价、持股价值、上次基础股息、全城待分红池和经营状态。没有持股显示明确空状态，估值不等于现金，待分红池不是本人的应收金额。
- F5：两处共用相同持股展示，原银行和募资卖股流程保留；资产中的明细只读，不能变为任意阶段卖股入口。
- F6：手机横屏、电脑和平板可滚动阅读，关键按钮44px，保留最高旋转提示、经营决定优先级和系统缩放；资源缓存统一更新。

## 约束与范围
服务端真实状态为来源，不改变价格、股数额度、交易阶段、任何Socket动作或计时。无新增框架。只用有限指定场景验证，不大规模模拟、不推送。

## 验收
- AC1/F1–F2：手机/平板/电脑非交易与旁人交易时可打开只读市场，资料完整、动作控件不存在，无服务端变化，关闭可用。
- AC2/F3：只读更新正常；本人交易窗口仍可加减、资产/转让返回并成交，草稿、期限和旧回执规则不变；进入强制决定时查看不能挡住原操作。
- AC3/F4–F5：本人持有自有和他人城市股票均完整列出，无持股显示空状态；与银行同份数据一致，原募资卖股仍可用。
- AC4/F6：三端可触达、方向阻挡与缓存/必要回归/lint通过，记录真实证据，仅本地交付。
