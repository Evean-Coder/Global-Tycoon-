# PC 中央地图铺满 Spec

## 背景与目标

PC 中央地图保留原图比例时出现灰色边带。用户明确要求将地图拉长铺满空隙。

## 功能需求

- F1：PC 中央世界地图分别适配内部矩形的宽、高，完整显示原图并铺满矩形，允许横纵比例变化。
- F2：窗口尺寸变化后仍贴合地块内边界；手机横屏现有铺满效果保持可用。

## 非功能需求与边界

- 使用现有本地地图，不修改规则、台账内容、棋盘顺序或联机动作；地图不拦截点击。
- 更新静态缓存版本；不强制刷新正在进行的对局。
- 只验证有限尺寸与实际交互，不运行整局模拟；当前禁止推送。

## 验收标准

- AC1（F1）：PC 标准、宽屏及平板矩形四边与内部地块边界贴合，图片成功加载，无灰色边带，完整图像拉伸填充。
- AC2（F2）：连续调整视口后地图重新贴合；手机横屏地图、台账、棋子与地块详情仍可用。
- AC3：静态版本一致且缓存升级验证通过，无新增服务端动作。
