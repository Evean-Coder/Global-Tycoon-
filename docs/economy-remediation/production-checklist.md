# 后期远航开支 Checklist（已批准）

2026-10-05。依据已批准的[规格](production-spec.md)、[设计](production-plan.md)和[31项任务](production-task.md)。共40项检查，C1–C40全部验证通过；用户在审批请求后回复“继续”，批准本文，按task开始开发。勾选仅代表实际验证通过，不代表预期。

## 记录与判定方式

每项记录实际输入/操作、结果和证据。测试输出保存命令、运行环境、退出码；可见流程保留截图或浏览器断言；有限对照保留登记、逐轨迹结果和预算。未通过记录原因及修复后的重验结果，未执行保持空白。

实现正确与长局效果分别判定。单元/浏览器检查通过不自动满足效果条件；效果不足则保持候选未启用，并明确长局目标未完成。受控测试不得计作正常对局或胜率样本。

- [x] C1：已完成79/80/119/120完整轮时，每回合费用依次为0/1500/1500/3000。（验证：四个边界分别结束个人回合，核对现金与收费事件。）
- [x] C2：已完成78/79及118/119轮时，分别预告第81/121完整轮生效，剩余2/1轮；其他阶段不会显示错误临近预告。（验证：查看这些轮次及相邻轮次的真实公开状态。）
- [x] C3：2/3/4人使用同一费用表，不因座位、策略、城市或机遇减免费用。（验证：各人数下不同座位及拥有租金减免的玩家，比较同阶段实际支出。）
- [x] C4：没有明确新经济修订的旧局和旧规则局，在后期仍不收费；明确修订的新测试局才收费。（验证：分别构造新旧状态并结束后期回合，核对版本、现金与事件。）
- [x] C5：费用以完整轮推进计数；个别玩家提前出局或自动跳过不使轮次重复完成，旧座位计数不会改变收费档位。（验证：运行非首座出局、多人跳过场景，比较完整轮与实际金额。）

## 二、一次结算与正常流程（AC2）

- [x] C6：足额现金结束正常回合，只扣一笔费用，之后正常换人；现金恰好付清时不会进入债务自救。（验证：分别用足额、恰好等额现金结束，核对下一玩家与事件数。）
- [x] C7：同一个人回合重复执行结算或重复发送相同动作，不再扣钱、不再产生费用事件；下一真实回合仍能正常计费。（验证：重复请求后再完成下一个个人回合，逐笔核对。）
- [x] C8：非法动作和过期动作被拒绝，正式现金、费用记录和回合进度不变。（验证：通过真实服务端提交无效请求，比较拒绝前后状态。）
- [x] C9：零费用阶段及已出局者不产生扣款事件；费用全归银行现金回收，其他玩家与城市基金不分得费用。（验证：比较所有玩家现金、基金与结构化事件的变化。）
- [x] C10：不合法金额或整数溢出被拒绝，不出现先扣现金后报错等部分修改。（验证：受控异常输入前后核对完整状态。）
- [x] C11：等待交易、拍卖、募资或股票操作时不提前收费；这些操作最终结束个人回合后才收费。（验证：逐个停留在等待阶段，再完成流程，比较事件产生时机。）
- [x] C12：极地和三回合监禁的合法跳过计费一次；入狱当次结束与以后跳过属于各自真实个人回合。（验证：执行入狱与后续跳过，逐回合核对金额、编号和事件。）
- [x] C13：一回合监禁自动跳过也计费一次；多人连续跳过后下一可操作玩家正确，不额外掷骰，不重复推进完整轮。（验证：自动跳过及全员监禁场景检查下一合法操作。）

## 三、自救、出售与连接（AC2）

- [x] C14：费用导致现金不足时进入既有资产自救，保持当前玩家与未结束回合；世界资讯、股票报价和完整轮不会提前更新。（验证：不足现金结束回合，检查债务来源和各项进度。）
- [x] C15：抵押、卖股和拆房补足现金后，只继续原回合结束；不重复收费、不重新处理落点。（验证：分别用三种资产操作自救，检查扣款次数和下一玩家。）
- [x] C16：自救拍卖/直接出售的成功、拒购、流拍及超时均保留正确债务续接；客户端伪造恢复信息无效。（验证：分别执行对应分支，检查恢复后可用操作与收费次数。）
- [x] C17：自动监禁跳过中的收费自救完成后，只完成该次跳过；普通旧落点债务自救仍按原落点继续。（验证：分别执行跳过自救与无新费用的旧落点自救。）
- [x] C18：无法自救按原方式破产清算，最后存活者获胜；断线只暂停时钟，重连显示原债务；超时处理不会多收或漏收。（验证：通过服务端走破产终局、断线/重连和强制操作超时，核对费用与胜者。）

## 四、公开信息与三端体验（AC3）

- [x] C19：不同玩家看到同一公开费用、完整轮与预告，快照不泄露身份令牌、隐藏选择或内部恢复信息。（验证：比较逐玩家快照及既有隐私回归结果。）
- [x] C20：世界资讯尚未发布时仍能看到当前费用；升档前两轮显示真实预告，当前规则清楚区分旧局与新修订局。（验证：打开上述真实测试局，核对资讯栏文字与现金。）
- [x] C21：PC布局能清晰显示费用、预告、资产和原操作，费用新增文字不遮挡棋盘或按钮。（验证：常用PC视口截图及浏览器可见/可点击断言。）
- [x] C22：平板横竖屏重排后费用、债务提示与自救操作均可读可点，无整页横向溢出。（验证：768×1024及1024×768视口执行自救查看。）
- [x] C23：320/375/430px手机宽度费用与预告可换行，完整棋盘及现有操作仍可用，无整页横向滚动。（验证：三种宽度比较页面滚动宽度并点按关键操作。）
- [x] C24：键盘焦点和系统缩放下规则、费用、自救弹窗可读可操作，未增加主动缴费按钮或改变原操作含义。（验证：键盘打开/关闭规则和自救操作，PC缩放检查布局，并走原动作入口。）
- [x] C25：更新后的页面与离线缓存取得一致的新资源，不出现费用显示缺失或静态资源加载失败。（验证：更新前缓存→刷新→重开，核对实际资源版本、费用文字及资源响应。）
