## 检查项

- [x] C1（AC1；T2–T3、T6）：购地解锁前不计数；连续第5回合不触发、第6回合完成触发，下次正常待掷骰展示。

- [x] C2（AC1；T2、T5）：机场不算城市；有机场但从未拥有城市按相同资格判断。

- [x] C3（AC2；T3–T4）：按购地决定当时的真实现金与资格判断；有能力却拒绝归零，当回合结束不再加一。

- [x] C4（AC2；T4、T6）：现金不足的机会计为无可负担机会；不得用回合结束资金回推历史。

- [x] C5（AC2；T3、T6）：监狱掷骰、冻结、跳过、飞行不计；同一回合经过多个决定或重复完成出口只计一次。

- [x] C6（AC2；T3）：自救挂起未完成不累计；偿清恢复后贯穿原turnId，只在回合真正完成时处理。

- [x] C7（AC2；T5）：分别验证普通购买、募资购地、拍卖、直接出售受让永久标记曾拥有；随后出售也不能刷资格。

- [x] C8（AC3；T7）：最多三座银行可售城市，按原地价升序、同价棋盘顺序；排除拍卖/未决出售占用，不预留库存。

- [x] C9（AC3；T7、T9–T10）：报价原价，无补贴/折扣；遵守原购地解锁和个人圈购买上限。

- [x] C10（AC3；T10）：整局最多成功一次；成功后used/everOwnedCity、产权、上市与购地计数一致，资格永久结束。

- [x] C11（AC4；T7、T12–T13）：取消、缺现金、缺库存或额度不足保留资格，具体原因可见，不自动代买。

- [x] C12（AC4；T12–T13）：直接掷骰收起入口不阻塞，未使用资格下次正常回合恢复；原期限不延长。

- [x] C13（AC5；T9）：候选被他人先买走或报价变化时拒绝且零修改；更新候选后由玩家重新选择确认，不能自动更换扣款目标。

- [x] C14（AC5；T9–T10）：非法身份、城市、阶段、现金、额度或报价失败前后完整状态一致，无部分产权/上市/扣款。

- [x] C15（AC5；T10–T11）：同一actionId重复、断线重试只成交一次；旧回执不能改变新决定，原结果获取语义保持。
