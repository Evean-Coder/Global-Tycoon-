# 主动经营核心优先数值自审

2026-10-16。候选修订，不是开发或发布记录。

## 修订原因

用户要求轻量趣味，核心仍为买地、正常落地建房、踩地收租。原订单普通净利最高2000、资讯最高2300，以及旧竞争全期9000名义附加，不能只靠“有风险”说明不会喧宾夺主。

## 数值约束

- 小订单保留预付本金与两次返还，基础净利200–600，保留原资讯10%收款奖励后最高760；本金返还不是净赚。
- 客源8%按基础租金，不对资讯再乘；单次600、两次、两完整轮，名义附加全期1200，竞价50–400。
- 订单/客源共用本人圈一次成功的轻经营额度；待开标先预留、落选返还圈资格但不返还本回合动作；同时只能有一个进行中的轻经营。
- 远程施工不改用户已批准费率、150%底价、三次起点冷却与同城限制。普通落地仍具有成本优势。

## 有限算术证据

`core-first-model.cjs`使用当前城市表和现有整数取整函数，10项检查通过；20城×5房级=100个静态状态、21个订单标的以及5400个很快完成的租金/资讯/持股/H4分配组合，0完整对局。结果见`core-first-results.json`。

- 当前普通订单最高2000、资讯2300；候选普通最高600、资讯760。
- 所有100个城市房级状态的两次名义客源附加，均不超过同地价标准增租基准的80%。该基准是地价30%；四级不能再升级，因此它是幅度对照，不是可执行的升五级操作。
- 资讯不扩大客源基数；同一次租金中增量资金与银行注资分别守恒。
- 不能漏掉只有城主自持2股的发行情况。600名义附加在该发行及H4条件下可让城主增收660；不能宣传为城主实际收入必然不超600。

## 不能据此认定通过的项目

没有真实开标、原子交易、个人租金优惠、跨圈额度、实际骰袋到访概率、UI或胜率证据；5400组是快速算术组合，不是5400场游戏。

仍需核对低价城、两人局是否常常不值得竞争，订单确定性是否使其他轻经营失去选择价值，以及远程建设的长期价值。优先有限局面与少量真实操作路径；不要为提高参与率而把金额直接加回原强度。

下一步设计应保持少量状态和提示，解释“正常掷骰和买建租仍是主循环”。用户未批准本稿的新数字实施；正式开发前按既有偏好完成四份独立文档并询问，发布保持暂停。
