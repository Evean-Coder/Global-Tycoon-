# 离线后的对局推进候选

日期：2026-10-09。状态：待需求确认，未实施；本文件不替代既有暂停规则。

用户反馈：离线暂停太生硬，手机切后台或网络波动容易使所有人不能继续。

## 已核查行为

任一存活玩家离线会立即暂停决定时钟，拒绝所有玩家动作；直到全部存活玩家重连才恢复。当前暂停没有自动解除时限。破产玩家离线不计入；无人在线由既有闲置清理结束。

## 推荐方向：只等待当前必要决策者

- 非当前必要决策者离线，显示小提示，其余玩家继续经营。
- 需要离线者操作时，建议最多给20秒重连等待，且不超过本次决定剩余时间；不能反复断线刷新等待额度。重连成功恢复原身份、状态、累计额度与剩余时限。
- 仍未回来时进入保守托管：掷骰、放弃购买/建造/飞行/股票交易、拒绝转让等必须逐项定义；冻结、监狱和自救的财产后果需单独确认，不能把“托管”解释成自由使用现金或自动出售资产。
- 同步机遇选择、多方竞拍/交易需要分别处理离线参与者，在线玩家仍有自己的原决定时限。
- 全员离线停止推进，保留闲置清理；不让无人对局持续自动运行。
- 在线者看见离线名单、当前等待原因和余时；离线者回到页面看到连接与恢复进度。短提示不遮地图和关键操作。
- 旧已开始对局是否迁移、主机转移、一次等待还是连续离线托管时限等，进入正式规格前确认；旧状态不能未经批准改变。

## 备选：保留全局暂停但加上限

全局最多暂停20秒，超时后离线者进入保守托管。改动较集中，但每次短断线仍影响所有人，也需要防止反复刷暂停和定义托管动作。

以上20秒是候选值，不是当前已上线规则。按用户指定ic-spec，这项涉及服务端规则变更，须单独完成并批准四份文档，再开发和有限验收。先完成手机及现有开局/股票卡点整改。
