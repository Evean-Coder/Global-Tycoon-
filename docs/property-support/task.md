# 置业扶持 Tasks

日期：2026-10-10。状态：用户已于本轮最终确认开发；当前实现与实际验证见 ../gameplay-improvements/progress.md。未勾选项目仍未完成逐项验收。

用户在整份Plan审批请求后回复“继续”，记录整体批准。以下仅覆盖置业扶持，主动经营次数和现有购买/时钟路径作为保护对象。

## 执行与文件约定

新增扶持模块与指定测试，修改文件列在每项中。按依赖实施，失败先修复，验证结果写入进度。回合完成与产权路径在T1核对实际函数，逐出口留证据；不另建购买或历史计数引擎。使用Node20及项目现有测试工具，不运行大量完整对局。

## T1 基线与入口清点

**文件：** docs/property-support/progress.md  
**依赖：** 无

**步骤：** 记录正常购地、募资、拍卖、直接出售受让、回合结束和原时钟入口，保护已有改动。

**验证：** 入口清单与当前代码逐项对应，记录既有回归结果。
